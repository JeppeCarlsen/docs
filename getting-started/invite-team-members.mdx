**Inviting team members to your Valiyou organization enables seamless collaboration on valuations, sponsorships, and analytics.** This guide walks you through the complete invitation process, from sending invites with customized role-based permissions to troubleshooting common acceptance issues. Learn how to grant appropriate access levels to ensure efficient team management and secure data handling.

<Info>
  This is a quick start guide for invitations. For comprehensive team management including permission control, removing users, and troubleshooting, see [Platform → Team Management](/platform/team-management).
</Info>

## Sending an Invitation

1. Navigate to **Platform** → **Users**
2. Click **"Invite User"** button (top right)
3. Enter team member's **email address**
4. Select **roles and permissions** in the tree:
   - **Admin**: Full access to everything
   - **Valuations**
     - **Dashboard**: Access valuation dashboard
     - **Valuations**: Create and manage valuations
       - **Edit Sales Value**: Modify sales values
       - **Edit Transfer Value**: Modify transfer values
       - **Edit Marketing Value**: Modify marketing values
       - **Edit Brand Value**: Modify brand values
     - **Reports**: View valuation reports
     - **Methods**: Configure valuation methods
   - **Sponsorships**
     - **Sponsors**: Manage sponsors
     - **Packages**: Create and manage packages
     - **Inventory**: Access item inventory
     - **Proposals**: Send and manage proposals
     - **Analytics**: View sponsorship analytics
   - **Platform**
     - **Users**: Invite and manage team members
     - **Organisation**: Modify organisation settings
     - **Billing**: Access billing and subscription
     - **Plugins**: Manage integrations
     - **API**: Manage API keys
   - **Approver**: Approve valuations (independent role)
5. Click **"Send Invitation"**

<Tip>
  **Admin Auto-Grant**: Checking "Admin" automatically grants all sub-permissions for full access.
</Tip>

## Team Member Receives Invitation

Your team member receives an email containing:

- Organization name
- Inviter's name
- Assigned roles/permissions
- Invitation link
- Expiration date

## Accepting the Invitation

<Frame>
  <img src="/images/valiyou.com_invite_3f3d0e3e-c69c-4695-8a8b-da2740ad08ad(iPad Pro)Youre_Invited.png" alt="Valiyou invitation acceptance page displaying welcome message and login options for new team members" />
</Frame>

### If They Have an Account

1. Click the invitation link
2. Log in with the **same email address** that received the invitation
3. Click "Accept Invitation"
4. Automatically redirected to the organization dashboard

### If They're New to Valiyou

1. Click the invitation link
2. Click "Sign Up"
3. Create an account using the **invited email address**
4. Verify their email
5. Return to the invitation link
6. Click "Accept Invitation"

<Frame>
  <img src="/images/valiyou.com_invite_3f3d0e3e-c69c-4695-8a8b-da2740ad08ad(iPad Pro)Create-your-account.png" alt="Valiyou account creation page for new users accepting team invitation with email verification flow" />
</Frame>

<Warning>
  **Email Matching Required**: The team member must log in or sign up with the exact email address that received the invitation. Invitations cannot be transferred to different email addresses.
</Warning>

## Common Issues

### Wrong Email Address

If logged in with a different email:

1. See "Wrong Account" message
2. Log out
3. Log in with correct email
4. Click invitation link again

<Frame>
  <img src="/images/valiyou.com_invite_3f3d0e3e-c69c-4695-8a8b-da2740ad08ad(iPad Pro)Wrong-Account.png" alt="Wrong account error message displayed when user attempts to accept invitation with incorrect email address in Valiyou" />
</Frame>

### Invitation Expired

If invitation has expired:

1. Contact organization admin
2. Request new invitation
3. Accept promptly

### Invitation Already Accepted

Link shows error message - this is a security feature. User should log in normally.

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="How many team members can I invite to my Valiyou organization?">
    The number of team members you can invite depends on your subscription plan. The Starter plan typically includes 3-5 seats, Professional plans offer 10-20 seats, and Enterprise plans provide unlimited user seats. You can check your current seat allocation in **Platform → Billing → Usage**. If you need more seats, you can upgrade your plan or purchase additional user seats.
  </Accordion>

  <Accordion title="Can I customize permissions for each team member individually?">
    Yes, Valiyou offers granular role-based access control. You can assign specific permissions for each module including Valuations, Sponsorships, and Platform settings. Each module has sub-permissions allowing you to control access at a detailed level. For example, you can grant someone access to view valuations but not edit them, or allow them to manage sponsors without accessing billing information.
  </Accordion>

  <Accordion title="What happens if a team member doesn't accept the invitation?">
    Invitations expire after 7 days for security reasons. If a team member hasn't accepted within this timeframe, they'll need to request a new invitation from your organization administrator. The invitation seat remains allocated to that email address until it expires or is manually cancelled, so you won't be charged for inactive invitations.
  </Accordion>

  <Accordion title="Can I change a team member's permissions after they've accepted?">
    Absolutely. Navigate to **Platform → Users**, find the team member in your list, and click the edit icon next to their name. You can modify their permissions at any time, and changes take effect immediately. The team member may need to refresh their browser to see updated access levels reflected in their interface.
  </Accordion>

  <Accordion title="How do I revoke access for a team member who's leaving?">
    To remove a team member, go to **Platform → Users**, locate the user in your team list, and click the remove or delete button. This immediately revokes their access to your organization and all associated data. Their user account remains active for other organizations they may belong to, but they lose all permissions and visibility to your organization's information.
  </Accordion>

  <Accordion title="Can team members belong to multiple organizations?">
    Yes, Valiyou users can be members of multiple organizations simultaneously. Each organization is completely separate with its own permissions, data, and billing. When a user logs in, they can switch between organizations using the organization selector in the top navigation. Permissions are organization-specific, so a user might be an Admin in one organization and have limited access in another.
  </Accordion>

  <Accordion title="What's the difference between Admin and Approver roles?">
    The Admin role grants full access to all features and settings within your organization, including billing, user management, and all modules. The Approver role is specifically designed for valuation workflow and allows users to approve valuations without accessing other sensitive areas like billing or organization settings. Approvers are typically stakeholders who need to review and authorize valuations but don't require broader platform access.
  </Accordion>

  <Accordion title="Do invited team members need to use the same email provider as the inviter?">
    No, team members can use any email provider (Gmail, Outlook, corporate email, etc.). The only requirement is that they must sign up or log in using the exact email address where they received the invitation. Email provider doesn't affect functionality, and users can even link multiple authentication methods (Google, Microsoft, LinkedIn) to their account after signup.
  </Accordion>

  <Accordion title="Can I resend an invitation if the original email was lost?">
    Yes, if an invitation hasn't expired or been accepted, you can resend it from **Platform → Users**. Look for pending invitations in your user list and click the resend option. If the invitation has already expired, you'll need to cancel the old invitation and send a new one. This ensures security and prevents multiple active invitation links for the same user.
  </Accordion>

  <Accordion title="Are there any security features for team collaboration?">
    Valiyou implements several security measures for team collaboration: invitation links expire after 7 days, email addresses must match exactly, role-based permissions prevent unauthorized access to sensitive data, and audit logs track all user activities. Additionally, organization administrators can enforce two-factor authentication and review access logs to monitor team member activities across all modules.
  </Accordion>
</AccordionGroup>
