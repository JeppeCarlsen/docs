Learn how to quickly invite colleagues to your Valiyou organization.

<Info>
  This is a quick start guide for invitations. For comprehensive team management including permission control, removing users, and troubleshooting, see [Platform → Team Management](/platform/team-management).
</Info>

## Sending an Invitation

1. Navigate to **Platform** → **Users**
2. Click **"Invite User"** button (top right)
3. Enter team member's **email address**
4. Select **roles and permissions** in the tree:
   - **Admin**: Full access to everything
   - **Reports**: Access analytics and reports
   - **Sales**: Manage sales values
   - **Transfer**: Manage transfers
   - **Marketing**: Manage marketing values
   - **Brand**: Manage brand indicators
   - **Users**: Invite and manage team members
   - **Billing**: Access billing and subscription
   - **Settings**: Modify organization settings
   - **Plugins**: Manage integrations
   - **Audit Log**: View activity logs (Enterprise)
   - **API**: Manage API keys
   - **Approver**: Approve valuations (independent role)
5. Click **"Send Invitation"**

<Tip>
  **Admin Auto-Grant**: Checking "Admin" automatically grants all sub-permissions for full access.
</Tip>

## Team Member Receives Invitation

Your team member receives an email containing:

- Organization name
- Inviter's name
- Assigned roles/permissions
- Invitation link
- Expiration date

## Accepting the Invitation

### If They Have an Account

1. Click the invitation link
2. Log in with the **same email address** that received the invitation
3. Click "Accept Invitation"
4. Automatically redirected to the organization dashboard

### If They're New to Valiyou

1. Click the invitation link
2. Click "Sign Up"
3. Create an account using the **invited email address**
4. Verify their email
5. Return to the invitation link
6. Click "Accept Invitation"

<Warning>
  **Email Matching Required**: The team member must log in or sign up with the exact email address that received the invitation. Invitations cannot be transferred to different email addresses.
</Warning>

## Common Issues

### Wrong Email Address

If logged in with a different email:

1. See "Wrong Account" message
2. Log out
3. Log in with correct email
4. Click invitation link again

### Invitation Expired

If invitation has expired:

1. Contact organization admin
2. Request new invitation
3. Accept promptly

### Invitation Already Accepted

Link shows error message - this is a security feature. User should log in normally.
