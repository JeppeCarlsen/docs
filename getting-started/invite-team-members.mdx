## Inviting Team Members

Valiyou uses a secure invitation system to add team members to your organization. Here's how it works:

### Step 1: Send an Invitation

1. Navigate to your organization settings or user management page
2. Click "Invite Member" or similar option
3. Enter the team member's **email address**
4. Select their **roles and permissions**:
   - **Admin** - Full access to all features and settings
   - **Valuations** - Access valuation management module:
     - **Dashboard** - View dashboard overview
     - **Valuations** - Create and manage valuations
       - **Edit Sales Value** - Modify sales value calculations (Enterprise only)
       - **Edit Transfer Value** - Modify transfer value calculations (Enterprise only)
       - **Edit Marketing Value** - Modify marketing value calculations (Enterprise only)
       - **Edit Brand Value** - Modify brand value calculations (Enterprise only)
     - **Reports** - Access valuation reports and analytics
     - **Methods** - Configure valuation methods and settings
   - **Sponsorships** - Access sponsorship management module:
     - **Sponsors** - Manage sponsor relationships and contracts
     - **Packages** - Create and manage sponsorship packages
     - **Library** - Access sponsorship item library
     - **Proposals** - Create and send sponsorship proposals
     - **Analytics** - View sponsorship analytics and reports
   - **Platform** - Access platform management features:
     - **Users** - Manage team members and invitations
     - **Settings** - Modify organization settings
     - **Billing** - Access billing and subscription management
     - **Plugins** - Manage integrations and plugins
     - **API** - Access API management and keys
   - **Approver** - Approve valuations and reports
   - **Audit Log** - View activity logs (Enterprise only)

<Note>
**Granular Permissions**: Enterprise plans unlock granular valuation permissions, allowing you to control which team members can edit specific value components (Sales, Transfer, Marketing, Brand).
</Note>

5. Click "Send Invitation"

### Step 2: Team Member Receives Invitation

Your team member will receive an invitation link via email. The invitation contains:

- Organization name
- Inviter's name
- Assigned roles
- Expiration date

### Step 3: Accept Invitation

The invited team member can accept by:

1. **If they have an account**:
   - Click the invitation link
   - Log in with the **same email address** that received the invitation
   - Click "Accept Invitation"
   - Automatically redirected to the organization dashboard

2. **If they're new to Valiyou**:
   - Click the invitation link
   - Click "Sign Up"
   - Create an account using the **invited email address**
   - Verify their email
   - Return to the invitation link
   - Click "Accept Invitation"

## Important Notes

<Warning>
**Email Matching Required**: The team member must log in or sign up with the exact email address that received the invitation. Invitations cannot be transferred to different email addresses.
</Warning>

<Info>
**Invitation Expiration**: Invitation links expire after a set period. If an invitation expires, you'll need to send a new one.
</Info>

<Tip>
**Multiple Roles**: You can assign multiple roles to a team member, giving them granular access to different features.
</Tip>

## Managing Team Members

Once team members have joined your organization, you can:

- **Update Roles**: Change their permissions at any time
- **Remove Members**: Remove team members from the organization
- **View Activity**: Track team member actions in the audit log

## Common Scenarios

### Wrong Email Address

If a team member clicks an invitation link but is logged in with a different email:

1. They'll see a "Wrong Account" message
2. They need to **log out**
3. Log in or sign up with the correct email address
4. Click the invitation link again

### Invitation Already Accepted

If someone tries to use an invitation link that's already been accepted, they'll see an error message. This is a security feature to prevent unauthorized access.

### Invitation Expired

If an invitation has expired:

1. Contact the organization admin
2. Request a new invitation be sent
3. Accept the new invitation promptly
