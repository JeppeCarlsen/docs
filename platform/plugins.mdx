**Extend Valiyou with powerful plugins that add AI-generated insights, advanced data visualizations, and social media analytics to your valuations and reports.** Access intelligent CSV importing from Salesforce, HubSpot, and Pipedrive, leverage free-tier AI providers like Groq and Google Gemini for automated analysis, and visualize cash flow with interactive Sankey charts. Enable plugins in minutes to enhance your sponsorship valuation workflow.

## Accessing Plugins

Navigate to **Platform** → **Plugins** from the sidebar to manage plugins.

<Note>
**Permission Required**: Plugins permission or Admin access required to enable/disable and configure plugins.
</Note>

## Available Plugins

### Universal CSV Importer

<Frame>
  <img src="/images/platform/plugins/universal-importer.png" alt="Universal CSV Importer plugin interface with file upload, auto-mapping controls, and CRM system selection for Salesforce, HubSpot, Pipedrive, and other platforms" />
</Frame>

<Note>
**Plan Required**: Professional or Enterprise plan
**Permission Required**: Sponsors permission (write access)
</Note>

**What it does**: Import sponsors and contacts from Salesforce, HubSpot, Pipedrive, and other CRM systems with intelligent auto-mapping.

**Where it appears**: Sponsorships → Sponsors page → "Import from CSV" button

**Supported CRM Systems**:
- **Salesforce** - Auto-detects and maps Salesforce CSV exports
- **HubSpot** - Auto-detects and maps HubSpot CSV exports
- **Pipedrive** - Auto-detects and maps Pipedrive CSV exports
- **Microsoft Dynamics** - Auto-detects and maps Dynamics CSV exports
- **Zoho CRM** - Auto-detects and maps Zoho CRM exports
- **Excel/Manual CSV** - Custom CSV files with manual field mapping
- **Other** - Generic CSV import

**Features**:
- Multi-file upload (sponsors + contacts)
- Intelligent auto-field mapping
- Confidence level indicators (High, Medium, Low)
- Relationship linking (contacts → sponsors)
- Duplicate detection
- Validation and error handling
- Preview before import
- Import results summary

**Benefits**:
- Migrate from existing CRM to Valiyou
- Import large datasets quickly
- Auto-link contacts to sponsors
- Reduce manual data entry

<Tip>
**Salesforce Users**: Export Account and Contact reports from Salesforce, then import directly into Valiyou with automatic field mapping.
</Tip>

See [Universal CSV Importer](/platform/plugins/universal-importer) for complete documentation.

### AI Insights for Reports

<Frame>
  <img src="/images/platform/plugins/ai-insights.png" alt="AI Insights configuration modal showing LLM provider selection with Groq, Google Gemini, OpenAI, Anthropic, and OpenRouter options with free tier badges and API key input fields" />
</Frame>

<Note>
**Plan Required**: Professional or Enterprise plan
**Permission Required**: Reports permission + Plugins permission
</Note>

**What it does**: Adds AI-generated insights and analysis to multi-valuation comparison reports using Large Language Models (LLMs).

**Where it appears**: Reports page → Compare multiple valuations → AI Insights section (after enabling plugin)

**Supported LLM Providers**:
- **Groq** (Free tier available) - Recommended for speed
- **Google Gemini** (Free tier available) - Good balance
- **OpenRouter** (Free tier available) - Multi-model access
- **OpenAI** (Paid) - GPT-4, GPT-3.5
- **Anthropic** (Paid) - Claude models

**Configuration**:
1. Select LLM Provider (dropdown with icons and "Free" badges)
2. Select Model (each provider has multiple models)
3. Enter API Key for selected provider
4. Save Configuration

**Benefits**:
- Automated insights from valuation data
- Trend analysis across multiple valuations
- Recommendations and observations
- Natural language explanations of patterns

<Tip>
**Free Options**: Groq, Google Gemini, and OpenRouter offer free tiers - perfect for trying AI Insights without cost.
</Tip>

See [Valuations → Reports](/valuations/reports#ai-insights) for usage details.

### Cash Flow Visualization (Sankey)

<Frame>
  <img src="/images/platform/plugins/cash-flow-sankey.png" alt="Interactive Sankey chart visualization showing revenue flow from sources to destinations with customizable colors, tooltips, and interactive flow diagrams in valuation details" />

<Note>
**Plan Required**: Professional or Enterprise plan
**Permission Required**: Automatically available with plan

- **Show Legend**: Toggle legend visibility
- **Show Tooltips**: Toggle interactive tooltips
- **Show Labels**: Toggle data labels
- **Enable Interactivity**: Toggle click/hover interactions
- **Animation Duration**: Milliseconds (default: 300ms)

**Benefits**:
- Visual revenue flow representation
- Interactive data exploration
- Customizable appearance
- Professional presentation

## Plugin Management

### Enabling a Plugin

**Process**:
1. Navigate to **Platform** → **Plugins**
2. Find the plugin card
3. Click **"Enable"** button (primary blue)
4. Plugin status changes to "Enabled" (green badge)
5. Configure button (gear icon) appears in header

**Requirements**:
- Plugin included in your plan (Professional/Enterprise)
- Required permissions (Reports for AI Insights)
- Not in demo mode

<Warning>
**Demo Mode**: Plugin actions are blocked in demo mode. Upgrade to enable/disable plugins.
</Warning>

### Disabling a Plugin

**Process**:
1. Find enabled plugin card (green "Enabled" badge)
2. Click **"Disable"** button (secondary gray)
3. Confirmation: Plugin disabled
4. Plugin status changes to "Disabled" (gray badge)
5. Feature disappears from pages (e.g., no AI Insights in Reports)

<Info>
**Reversible**: Disabling a plugin removes features but preserves configuration. Re-enabling restores settings.
</Info>

### Configuring a Plugin

**Available for**:
- AI Insights for Reports
- Cash Flow Visualization
- SocialDeepDive

**Process**:
1. Find enabled plugin card
2. Click **gear icon** (⚙️) in card header
3. Configuration modal opens
4. Adjust settings
5. Click **"Save Configuration"**
6. Settings applied immediately

<Tip>
**Live Updates**: Configuration changes apply to all future uses immediately. Existing reports/valuations remain unchanged.
</Tip>

## Plugin Cards

Grid layout (2 columns on desktop, 1 on mobile) with detailed plugin information.

### Card Structure

**Card Header**:
- Plugin Name (title)
- Configure button (gear icon, if applicable)
- Edit Prompt button (ellipsis icon, super admin only, AI Insights)

**Card Body**:
- **Description**: What the plugin does
- **Author**: Plugin creator (if specified)
- **Status**: Enabled (green) or Disabled (gray) badge
- **Health**: Health status (if enabled)
  - Healthy (green checkmark)
  - Degraded (yellow warning)
  - Unhealthy (red error)
- **LLM Provider**: Current AI provider (AI Insights only)
- **Plan Warning**: Yellow box if plugin not in current plan

**Card Footer**:
- **Enable** button (primary blue) - If disabled
- **Disable** button (secondary gray) - If enabled
- **Upgrade Required** button (disabled) - If not in plan

### Health Indicators

**Healthy**:
- Green badge + green checkmark icon
- Plugin functioning normally
- No issues detected

**Degraded**:
- Yellow badge + yellow warning icon
- Plugin working but with issues
- May have reduced functionality
- Health message explains issue

**Unhealthy**:
- Red badge + red error icon
- Plugin not functioning properly
- Feature may be unavailable
- Health message explains error

**Unknown**:
- Gray badge + clock icon
- Health status not checked
- Recent enable or disable

<Info>
**Auto-Check**: Plugin health is checked automatically. Refresh page to see latest status.
</Info>

## Common Use Cases

### Setting Up AI Insights (Free)

1. Navigate to **Platform** → **Plugins**
2. Find "AI Insights for Reports" card
3. Click **"Enable"** button
4. Wait for status to change to "Enabled"
5. Click **gear icon** (⚙️) in card header
6. Select **"Groq"** (free) or **"Google Gemini"** (free)
7. Select recommended model (free badge)
8. Enter API key (get from [Groq](https://console.groq.com) or [Google AI Studio](https://aistudio.google.com))
9. Click **"Save Configuration"**
10. Go to **Valuations** → **Reports**
11. Select 2+ valuations
12. See AI Insights section with analysis

### Customizing Sankey Chart

1. Navigate to **Platform** → **Plugins**
2. Find "Cash Flow Visualization" card
3. If disabled, click **"Enable"** first
4. Click **gear icon** (⚙️) in card header
5. Adjust settings:
   - Chart Type: Keep as Sankey
   - Height: 800px (taller chart)
   - Color Scheme: Blue (brand colors)
   - Position: Before Sales Details
   - Keep all checkboxes checked
6. Click **"Save Configuration"**
7. Open any **Valuation Details** page
8. See customized Sankey chart

### Disabling Unused Plugin

1. Navigate to **Platform** → **Plugins**
2. Find enabled plugin (green "Enabled" badge)
3. Click **"Disable"** button
4. Plugin status changes to "Disabled"
5. Feature removed from pages
6. Configuration preserved for future re-enable

## Troubleshooting

### Can't Enable Plugin

**Reasons**:
- Plugin not included in plan (upgrade required)
- No Plugins permission (request from admin)
- In demo mode (upgrade to paid plan)
- Missing required permission (e.g., Reports for AI Insights)

**Fix**:
- Check plan tier (Professional/Enterprise required)
- Purchase plugin add-on: [Platform → Billing](/platform/billing/billing)
- Request Plugins permission from admin
- Upgrade from demo mode
- Request missing permissions (Reports, etc.)

### Configuration Not Saving

**Check**:
- API key provided (AI Insights)
- Valid format (numbers, no negatives for height/duration)
- Network connection stable
- Not in demo mode

**Try**:
- Ensure API key is complete (starts with correct prefix)
- Use positive numbers for pixel/millisecond values
- Refresh page and try again
- Check browser console for errors

### Plugin Showing "Unhealthy"

**Reasons**:
- API key invalid or expired (AI Insights)
- Service temporarily unavailable
- Rate limit exceeded
- Configuration error

**Fix**:
- Re-enter API key (check validity)
- Wait and try again later
- Check usage limits on provider dashboard
- Re-configure plugin with correct settings
- Disable and re-enable plugin

### AI Insights Not Appearing

**Check**:
- Plugin enabled (green "Enabled" badge)
- Reports permission granted
- Professional/Enterprise plan active
- Multiple valuations selected (2+ required)
- API key configured correctly

**Fix**:
- Enable AI Insights plugin
- Request Reports permission
- Upgrade plan
- Select at least 2 valuations
- Reconfigure API key

### Sankey Chart Not Showing

**Check**:
- Plugin enabled
- Professional/Enterprise plan
- Viewing Valuation Details page (not list)
- Chart position setting (might be bottom of page)

**Fix**:
- Enable Cash Flow Visualization plugin
- Upgrade plan
- Open a single valuation details page
- Check configuration position setting
- Scroll down if position set to bottom

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="What plugins are available in Valiyou?">
    Valiyou offers four powerful plugins: **Universal CSV Importer** for importing sponsors and contacts from CRM systems like Salesforce, HubSpot, and Pipedrive; **AI Insights for Reports** that uses LLM providers (Groq, Google Gemini, OpenAI, Anthropic, OpenRouter) to generate automated analysis; **Cash Flow Visualization** with interactive Sankey charts; and **SocialDeepDive** for social media analytics across 12 platforms including Instagram, Facebook, YouTube, TikTok, and LinkedIn.
  </Accordion>

  <Accordion title="How do I enable plugins in Valiyou?">
    To enable plugins, navigate to **Platform** → **Plugins** from the sidebar, find the plugin card you want to activate, and click the **"Enable"** button. The plugin status will change to "Enabled" (green badge), and a configuration button (gear icon) will appear if the plugin has settings. You need the Plugins permission or Admin access, and plugins must be included in your Professional or Enterprise plan. Demo mode accounts cannot enable plugins.
  </Accordion>

  <Accordion title="Are Valiyou plugins free or paid?">
    Plugin availability depends on your plan. The Universal CSV Importer, AI Insights, Cash Flow Visualization, and SocialDeepDive plugins require a **Professional or Enterprise plan**. However, the AI Insights plugin can use **free-tier LLM providers** like Groq, Google Gemini, and OpenRouter, so you can access AI-generated insights without additional AI service costs beyond your Valiyou subscription.
  </Accordion>

  <Accordion title="Which AI providers support free tiers for AI Insights?">
    Three AI providers offer free tiers for the AI Insights plugin: **Groq** (recommended for speed, with free models like llama-3.3-70b-versatile), **Google Gemini** (good balance, with free models like gemini-2.0-flash-exp and gemini-1.5-pro), and **OpenRouter** (multi-model access with free tier options). All three providers are marked with "Free" badges in the configuration modal, making it easy to identify cost-free options.
  </Accordion>

  <Accordion title="Can I use plugins in demo mode?">
    No, plugin actions are blocked in demo mode. You cannot enable, disable, or configure plugins while using a demo account. To access plugin functionality, you need to upgrade to a paid plan (Professional or Enterprise). Once upgraded, you'll be able to manage all plugins included in your plan subscription.
  </Accordion>

  <Accordion title="What is the Universal CSV Importer plugin?">
    The **Universal CSV Importer** is a plugin that allows you to import sponsors and contacts from CRM systems like Salesforce, HubSpot, Pipedrive, Microsoft Dynamics, and Zoho CRM. It features intelligent auto-field mapping with confidence level indicators, multi-file upload support, relationship linking between contacts and sponsors, duplicate detection, and preview-before-import functionality. This plugin appears on the Sponsorships → Sponsors page as an "Import from CSV" button.
  </Accordion>

  <Accordion title="How does AI Insights work in Valiyou?">
    AI Insights uses Large Language Models (LLMs) to automatically generate analysis and insights from your valuation data. After enabling the plugin and configuring an LLM provider (like Groq or Google Gemini), you can compare 2+ valuations in the Reports page to see an AI Insights section with trend analysis, recommendations, observations, and natural language explanations of patterns in your data. The AI processes your valuation metrics and provides actionable intelligence.
  </Accordion>

  <Accordion title="Can I customize the Sankey chart visualization?">
    Yes, the Cash Flow Visualization plugin is highly customizable. You can configure the chart type (Sankey, Waterfall, or Custom), chart height in pixels, color scheme (Default multi-color, Blue, Green, Purple, or Custom), chart position (Before Sales, After Sales, Top of Page, or Bottom of Page), and toggle features like legend, tooltips, labels, and interactivity. You can also adjust animation duration in milliseconds. All settings are accessible through the configuration modal (gear icon).
  </Accordion>

  <Accordion title="What permissions do I need to use plugins?">
    Permission requirements vary by plugin. The **Universal CSV Importer** requires Sponsors permission with write access. **AI Insights** requires both Reports permission and Plugins permission. **Cash Flow Visualization** and **SocialDeepDive** require Plugins permission. Admin users can always enable, disable, and configure all plugins regardless of specific permissions. If you lack required permissions, request them from your organization administrator.
  </Accordion>

  <Accordion title="How do I troubleshoot unhealthy plugins?">
    When a plugin shows "Unhealthy" status (red badge with error icon), common causes include invalid or expired API keys (for AI Insights), service unavailability, rate limit exceeded, or configuration errors. To fix: **re-enter your API key** and verify it's valid, **wait and retry** if the service is temporarily down, **check usage limits** on your provider's dashboard, **reconfigure the plugin** with correct settings, or try **disabling and re-enabling** the plugin. The health message will explain the specific issue detected.
  </Accordion>
</AccordionGroup>
