**Extend Valiyou with powerful plugins that add advanced data visualizations, social media analytics, and your own private AI provider to your valuations and reports.** Access intelligent CSV importing from Salesforce, HubSpot, and Pipedrive, connect your own AI provider for data-sovereignty-compliant analysis, and visualize cash flow with interactive Sankey charts. ## Accessing Plugins

Navigate to **Platform** → **Plugins** from the sidebar to manage plugins.

  **Permission Required**: Plugins permission or Admin access required to enable/disable and
  configure plugins.
</Note>

## Available Plugins

### Universal CSV Importer

<Note>
  **Plan Required**: Professional or Enterprise plan **Permission Required**: Sponsors permission
  (write access)
</Note>

**What it does**: Import sponsors and contacts from Salesforce, HubSpot, Pipedrive, and other CRM systems with intelligent auto-mapping.

**Where it appears**: Sponsorships → Sponsors page → "Import from CSV" button

**Supported CRM Systems**:

- **Salesforce** - Auto-detects and maps Salesforce CSV exports
- **HubSpot** - Auto-detects and maps HubSpot CSV exports
- **Pipedrive** - Auto-detects and maps Pipedrive CSV exports
- **Microsoft Dynamics** - Auto-detects and maps Dynamics CSV exports
- **Zoho CRM** - Auto-detects and maps Zoho CRM exports
- **Excel/Manual CSV** - Custom CSV files with manual field mapping
- **Other** - Generic CSV import

**Features**:

- Multi-file upload (sponsors + contacts)
- Intelligent auto-field mapping
- Confidence level indicators (High, Medium, Low)
- Relationship linking (contacts → sponsors)
- Duplicate detection
- Validation and error handling
- Preview before import
- Import results summary

**Benefits**:

- Migrate from existing CRM to Valiyou
- Import large datasets quickly
- Auto-link contacts to sponsors
- Reduce manual data entry

<Tip>
  **Salesforce Users**: Export Account and Contact reports from Salesforce, then import directly
  into Valiyou with automatic field mapping.
</Tip>

See [Universal CSV Importer](/platform/plugins/universal-importer) for complete documentation.

### Private AI Connection

<Frame>
  <img
    src="/images/platform/plugins/ai-insights.png"
    alt="Private AI Connection configuration modal showing provider selection with Anthropic, OpenAI, Google Gemini, Mistral, Azure OpenAI, Amazon Bedrock, and Google Vertex AI options"
  />
</Frame>

<Note>
  **Plan Required**: Professional (add-on, 300 kr/month) or Enterprise (included) **Permission
  Required**: Reports permission + Plugins permission
</Note>

**What it does**: Connects your organization's own AI provider account to Valiyou, routing both the AI chat assistant and AI Key Insights in Reports through your credentials instead of Valiyou's default AI. Data is processed under your own DPA with the provider.

**Where it appears**: Platform → Plugins → Private AI Connection (configure); Reports page → AI Key Insights section shows your provider name once connected

**Supported Providers**:

Simple (provider + API key):

- **Anthropic** — Claude models
- **OpenAI** — GPT-4o models
- **Google Gemini** — Gemini 1.5/2.0 models
- **Mistral** — Mistral Large, Small, Nemo

Enterprise (provider + credentials):

- **Azure OpenAI** — resource name, deployment, API version, key
- **Amazon Bedrock** — AWS region, access key, secret
- **Google Vertex AI** — GCP project, region, service account

**Configuration**:

1. Enable the plugin and click the gear icon
2. Select your provider
3. Enter your API key (simple) or full credentials (enterprise)
4. Save — status changes to Connected (green)

**Benefits**:

- Data processed under your own DPA
- EU hosting options with Azure, Vertex AI, or Bedrock
- Leverage existing enterprise provider agreements
- Full control over which provider model handles your data

See [Private AI Connection](/platform/plugins/ai-insights) for full setup documentation.

### Cash Flow Visualization (Sankey)

<Frame>
  <img
    src="/images/platform/plugins/cash-flow-sankey.png"

<Note>

**What it does**: Adds interactive Sankey (flow) charts to valuation details showing revenue flow visualization.

**Configuration Options**:

- **Chart Type**: Sankey, Waterfall, or Custom
- **Chart Height**: Pixels (default: 600px)
- **Color Scheme**: Default (multi-color), Blue, Green, Purple, Custom
- **Chart Position**: Before Sales, After Sales, Top of Page, Bottom of Page
- **Show Legend**: Toggle legend visibility
- **Show Tooltips**: Toggle interactive tooltips
- **Show Labels**: Toggle data labels
- **Enable Interactivity**: Toggle click/hover interactions
- **Animation Duration**: Milliseconds (default: 300ms)

**Benefits**:

- Visual revenue flow representation
- Interactive data exploration
- Customizable appearance
- Professional presentation

See [Valuations → Valuation Details](/valuations/valuation-details#cash-flow-visualization) for usage details.

## Plugin Management

### Enabling a Plugin

**Process**:

1. Navigate to **Platform** → **Plugins**
2. Find the plugin card
3. Click **"Enable"** button (primary blue)
4. Plugin status changes to "Enabled" (green badge)
5. Configure button (gear icon) appears in header

**Requirements**:

- Plugin included in your plan (Professional/Enterprise)
- Required permissions (Reports for Private AI Connection)
- Not in demo mode

<Warning>
  **Demo Mode**: Plugin actions are blocked in demo mode. Upgrade to enable/disable plugins.
</Warning>

### Disabling a Plugin

**Process**:

1. Find enabled plugin card (green "Enabled" badge)
2. Click **"Disable"** button (secondary gray)
3. Confirmation: Plugin disabled
4. Plugin status changes to "Disabled" (gray badge)
5. AI features revert to Valiyou's built-in AI

<Info>
  **Reversible**: Disabling a plugin removes features but preserves configuration. Re-enabling
  restores settings.
</Info>

### Configuring a Plugin

**Available for**:

- Private AI Connection
- Cash Flow Visualization
- SocialDeepDive

**Process**:

1. Find enabled plugin card
2. Click **gear icon** (⚙️) in card header
3. Configuration modal opens
4. Adjust settings
5. Click **"Save Configuration"**
6. Settings applied immediately

<Tip>
  **Live Updates**: Configuration changes apply to all future uses immediately. Existing
  reports/valuations remain unchanged.
</Tip>

## Plugin Cards

Grid layout (2 columns on desktop, 1 on mobile) with detailed plugin information.

### Card Structure

**Card Header**:

- Plugin Name (title)
- Configure button (gear icon, if applicable)
- Edit Prompt button (ellipsis icon, super admin only, Private AI Connection)

**Card Body**:

- **Description**: What the plugin does
- **Author**: Plugin creator (if specified)
- **Status**: Enabled (green) or Disabled (gray) badge
- **Health**: Health status (if enabled)
  - Healthy (green checkmark)
  - Degraded (yellow warning)
  - Unhealthy (red error)
- **LLM Provider**: Current AI provider (Private AI Connection only)
- **Plan Warning**: Yellow box if plugin not in current plan

**Card Footer**:

- **Enable** button (primary blue) - If disabled
- **Disable** button (secondary gray) - If enabled
- **Upgrade Required** button (disabled) - If not in plan

### Health Indicators

**Healthy**:

- Green badge + green checkmark icon
- Plugin functioning normally
- No issues detected

**Degraded**:

- Yellow badge + yellow warning icon
- Plugin working but with issues
- May have reduced functionality
- Health message explains issue

**Unhealthy**:

- Red badge + red error icon
- Plugin not functioning properly
- Feature may be unavailable
- Health message explains error

**Unknown**:

- Gray badge + clock icon
- Health status not checked
- Recent enable or disable

<Info>
  **Auto-Check**: Plugin health is checked automatically. Refresh page to see latest status.
</Info>

## Common Use Cases

### Setting Up Private AI Connection

1. Navigate to **Platform** → **Plugins**
2. Find the **"Private AI Connection"** card
3. Click **"Enable"** button
4. Click **gear icon** (⚙️) in card header
5. Select your provider (e.g., Anthropic, OpenAI, Gemini, Mistral)
6. Enter your API key
7. Click **"Save Configuration"**
8. Plugin status changes to **"Connected"** (green)
9. Go to **Valuations** → **Reports**
10. Select 2+ valuations and click **"Get AI Key Insights"**
11. AI Key Insights section shows your provider name as the source

### Customizing Sankey Chart

1. Navigate to **Platform** → **Plugins**
2. Find "Cash Flow Visualization" card
3. If disabled, click **"Enable"** first
4. Click **gear icon** (⚙️) in card header
5. Adjust settings:
   - Chart Type: Keep as Sankey
   - Height: 800px (taller chart)
   - Color Scheme: Blue (brand colors)
   - Position: Before Sales Details
   - Keep all checkboxes checked
6. Click **"Save Configuration"**
7. Open any **Valuation Details** page
8. See customized Sankey chart

### Disabling Unused Plugin

1. Navigate to **Platform** → **Plugins**
2. Find enabled plugin (green "Enabled" badge)
3. Click **"Disable"** button
4. Plugin status changes to "Disabled"
5. Feature removed from pages
6. Configuration preserved for future re-enable

## Troubleshooting

### Can't Enable Plugin

**Reasons**:

- Plugin not included in plan (upgrade required)
- No Plugins permission (request from admin)
- In demo mode (upgrade to paid plan)
- Missing required permission (e.g., Reports for Private AI Connection)

**Fix**:

- Check plan tier (Professional/Enterprise required)
- Purchase plugin add-on: [Platform → Billing](/platform/billing/billing)
- Request Plugins permission from admin
- Upgrade from demo mode
- Request missing permissions (Reports, etc.)

### Configuration Not Saving

**Check**:

- API key provided (Private AI Connection)
- Valid format (numbers, no negatives for height/duration)
- Network connection stable
- Not in demo mode

**Try**:

- Ensure API key is complete (starts with correct prefix)
- Use positive numbers for pixel/millisecond values
- Refresh page and try again
- Check browser console for errors

### Plugin Showing "Unhealthy"

**Reasons**:

- API key invalid or expired (Private AI Connection)
- Service temporarily unavailable
- Rate limit exceeded
- Configuration error

**Fix**:

- Re-enter API key (check validity)
- Wait and try again later
- Check usage limits on provider dashboard
- Re-configure plugin with correct settings
- Disable and re-enable plugin

### AI Key Insights Not Appearing

**Check**:

- Reports permission granted
- Professional/Enterprise plan active
- Multiple valuations selected (2+ required)
- If using Private AI Connection: plugin status is "Connected" (green), not "Setup Required"

**Fix**:

- Request Reports permission
- Upgrade plan
- Select at least 2 valuations
- If using Private AI Connection: open plugin configuration and enter or update API key

### Sankey Chart Not Showing

**Check**:

- Plugin enabled
- Professional/Enterprise plan
- Viewing Valuation Details page (not list)
- Chart position setting (might be bottom of page)

**Fix**:

- Enable Cash Flow Visualization plugin
- Upgrade plan
- Open a single valuation details page
- Check configuration position setting
- Scroll down if position set to bottom

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="What plugins are available in Valiyou?">
    Valiyou offers four plugins: **Universal CSV Importer** for importing sponsors and contacts from CRM systems like Salesforce, HubSpot, and Pipedrive; **Private AI Connection** for connecting your own AI provider (Anthropic, OpenAI, Gemini, Mistral, Azure OpenAI, Bedrock, Vertex AI) to route AI features under your own DPA; **Cash Flow Visualization** with interactive Sankey charts; and **SocialDeepDive** for social media analytics across 12 platforms including Instagram, Facebook, YouTube, TikTok, and LinkedIn.
  </Accordion>

<Accordion title="How do I enable plugins in Valiyou?">
  To enable plugins, navigate to **Platform** → **Plugins** from the sidebar, find the plugin card
  you want to activate, and click the **"Enable"** button. The plugin status will change to
  "Enabled" (green badge), and a configuration button (gear icon) will appear if the plugin has
  settings. You need the Plugins permission or Admin access, and plugins must be included in your
  Professional or Enterprise plan. Demo mode accounts cannot enable plugins.
</Accordion>

<Accordion title="Do I need a plugin to use AI Insights in Reports?">
  No. AI Key Insights in Reports are available on all Professional and Enterprise plans using
  Valiyou's built-in AI — no plugin or API key needed. The **Private AI Connection** plugin is only
  needed if you want to route AI processing through your own provider account under your own data
  processing agreement (DPA).
</Accordion>

<Accordion title="What is Private AI Connection and why would I use it?">
  Private AI Connection lets your organization connect its own AI provider (Anthropic, OpenAI,
  Gemini, Mistral, Azure OpenAI, Amazon Bedrock, or Google Vertex AI) to Valiyou. When configured,
  all AI features — including the chat assistant and AI Key Insights in Reports — route through your
  credentials instead of Valiyou's default AI. This is useful for organizations that need data
  processed under their own DPA, want EU-hosted AI providers, or already have enterprise agreements
  with a specific provider.
</Accordion>

<Accordion title="Can I use plugins in demo mode?">
  No, plugin actions are blocked in demo mode. You cannot enable, disable, or configure plugins
  while using a demo account. To access plugin functionality, you need to upgrade to a paid plan
  (Professional or Enterprise). Once upgraded, you'll be able to manage all plugins included in your
  plan subscription.
</Accordion>

<Accordion title="What is the Universal CSV Importer plugin?">
  The **Universal CSV Importer** is a plugin that allows you to import sponsors and contacts from
  CRM systems like Salesforce, HubSpot, Pipedrive, Microsoft Dynamics, and Zoho CRM. It features
  intelligent auto-field mapping with confidence level indicators, multi-file upload support,
  relationship linking between contacts and sponsors, duplicate detection, and preview-before-import
  functionality. This plugin appears on the Sponsorships → Sponsors page as an "Import from CSV"
  button.
</Accordion>

<Accordion title="Can I customize the Sankey chart visualization?">
  Yes, the Cash Flow Visualization plugin is highly customizable. You can configure the chart type
  (Sankey, Waterfall, or Custom), chart height in pixels, color scheme (Default multi-color, Blue,
  Green, Purple, or Custom), chart position (Before Sales, After Sales, Top of Page, or Bottom of
  Page), and toggle features like legend, tooltips, labels, and interactivity. You can also adjust
  animation duration in milliseconds. All settings are accessible through the configuration modal
  (gear icon).
</Accordion>

<Accordion title="What permissions do I need to use plugins?">
  Permission requirements vary by plugin. The **Universal CSV Importer** requires Sponsors
  permission with write access. **Private AI Connection** requires both Reports permission and
  Plugins permission. **Cash Flow Visualization** and **SocialDeepDive** require Plugins permission.
  Admin users can always enable, disable, and configure all plugins regardless of specific
  permissions. If you lack required permissions, request them from your organization administrator.
</Accordion>

  <Accordion title="How do I troubleshoot unhealthy plugins?">
    When a plugin shows "Unhealthy" status (red badge with error icon), common causes include invalid or expired API keys (for Private AI Connection), service unavailability, rate limit exceeded, or configuration errors. To fix: **re-enter your API key** and verify it's valid, **wait and retry** if the service is temporarily down, **check usage limits** on your provider's dashboard, **reconfigure the plugin** with correct settings, or try **disabling and re-enabling** the plugin. The health message will explain the specific issue detected.
  </Accordion>
</AccordionGroup>
