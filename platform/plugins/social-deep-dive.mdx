## Features (Planned)

### Automatic Weighted Averages

Calculate overall social media performance across all platforms:
- Platform-specific weighting based on importance
- Customizable weights per platform
- Aggregate engagement scores
- Trend analysis over time

### Cross-Platform Comparison

Compare performance across platforms:
- Identify top-performing channels
- Spot underperforming platforms
- Optimize resource allocation
- Benchmark against industry averages

### Engagement Metrics

Track detailed engagement across platforms:
- **Followers/Subscribers**: Total audience size
- **Impressions**: Content reach
- **Engagements**: Likes, comments, shares
- **Engagement Rate**: Engagement / Impressions
- **Growth Rate**: Follower growth over time

### Platform-Specific Insights

Deep dive into each platform:
- Instagram: Story views, reel performance
- YouTube: Watch time, retention rates
- TikTok: Video views, viral content
- LinkedIn: Post reach, connection growth
- Facebook: Page reach, post engagement

### Automated Data Collection

Connect platform APIs for automatic updates:
- Scheduled data refresh (daily/weekly)
- Historical trend tracking
- Anomaly detection
- Performance alerts

## Configuration

### Step 1: Enable Plugin

1. Navigate to **Platform** → **Plugins**
2. Find "SocialDeepDive for Valuation" card
3. Click **"Enable"** button
4. Wait for status to change to "Enabled"

<Note>
**Early Access**: Plugin is enabled but features are still in development. You'll receive access as features launch.
</Note>

### Step 2: Configure Platforms

1. Click **gear icon** (⚙️) in plugin card header
2. Configuration modal opens

<Frame>
  <img src="/images/platform/plugins/social-deep-dive-config.png" alt="Social media analytics configuration modal for Instagram analytics, Facebook insights, and TikTok metrics integration settings" />
</Frame>

**Platform Selection**:

Select which platforms you want to track:
- ☑️ Instagram
- ☑️ Facebook
- ☑️ YouTube
- ☑️ TikTok
- ☑️ LinkedIn
- ☑️ Reddit
- ☑️ Tumblr
- ☑️ Slack
- ☑️ Vimeo
- ☑️ Behance
- ☑️ Yelp
- ☑️ Flickr

<Info>
**Default**: All platforms enabled by default. Uncheck platforms you don't use.
</Info>

### Step 3: Platform-Specific Settings

For each enabled platform, configure:
- **API Credentials** (optional, for automatic data collection)
- **Account/Channel URL**
- **Weighting Factor** (1-10, importance for aggregated scores)
- **Data Refresh Frequency** (daily, weekly, manual)

### Step 4: Save Configuration

Click **"Save Configuration"** to apply changes.

  <Accordion title="How are weighted averages calculated for social media analytics?">
    **Formula** (when available):
    ```
    Overall Score = Σ(Platform Score × Weight) / Σ(Weights)
    ```

    **Example**:
    - Instagram: 85/100, Weight: 10
    - Facebook: 70/100, Weight: 7
    - YouTube: 90/100, Weight: 8

    Overall Score = (85×10 + 70×7 + 90×8) / (10+7+8) = 81.4/100

    Weights are customizable per platform.
  </Accordion>

  <Accordion title="Can I import historical social media data?">

    **Workaround**: Create valuations with historical dates and manually enter social media metrics from past periods.
