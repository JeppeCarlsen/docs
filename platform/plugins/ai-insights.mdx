## Private AI Connection

<Frame>
  <img
    src="/images/platform/plugins/ai-insights.png"

**Private AI Connection lets your organization connect its own AI provider to Valiyou.** By default, Valiyou's built-in AI powers both the AI assistant and the AI Key Insights in Reports. Private AI Connection replaces that with your own provider account — so data is processed under your organization's existing data processing agreement (DPA), optionally with EU-hosted providers.

<Note>
  **Plan Required**: Professional (add-on, 300 kr/month) or Enterprise (included) **Permission
  Required**: Reports permission + Plugins permission
</Note>

**What it does**: Routes all AI features — chat assistant and Reports insights — through your chosen provider and API key instead of Valiyou's default AI.

**Where it appears**: Platform → Plugins → Private AI Connection

**Author**: Valiyou

## Why Use Private AI Connection?

Most organizations are well-served by Valiyou's built-in AI. Private AI Connection is for organizations that need:

- **Data sovereignty**: All AI processing happens under your own DPA with the provider
- **EU hosting**: Choose a provider and region that keeps data within the EU
- **Existing agreements**: Leverage enterprise agreements you already have with OpenAI, Anthropic, Azure, or Google
- **Compliance requirements**: Regulated industries where the AI processor must be named in your DPA

## Configuration

### Step 1: Navigate to Plugins

1. Go to **Platform** → **Plugins**
2. Find the **Private AI Connection** card
3. Click **"Enable"** if not already enabled
4. Click the **gear icon** (⚙️) in the card header to open configuration

### Step 2: Select Your Provider

Choose your AI provider from the dropdown. Simple providers show only a provider field and API key field. Enterprise providers show additional credential fields specific to that provider.

<Frame>
  <img
    src="/images/platform/plugins/ai-insights-config-modal.png"
    alt="Private AI Connection configuration modal showing provider selection dropdown and API key input"
  />
</Frame>

### Step 3: Enter Credentials

**Simple providers** (Anthropic, OpenAI, Gemini, Mistral):

1. Select provider from dropdown
2. Enter your API key in the **API Key** field
3. Click **"Save Configuration"**

**Enterprise providers** (Azure OpenAI, Bedrock, Vertex AI):

1. Select provider from dropdown
2. Fill in all required credential fields (resource name, region, project ID, etc.)
3. Click **"Save Configuration"**

<Warning>
  **API Key Required**: You must enter a valid API key before saving. If the key is missing, a
  warning will appear: "Please enter a valid [Provider] API key before saving."
</Warning>

### Step 4: Verify Connection

After saving, the plugin card shows one of three status badges:

- **Connected** (green) — credentials verified, AI features are routing through your provider
- **Setup Required** (yellow) — plugin enabled but credentials are missing or incomplete
- **Disabled** (gray) — plugin is not enabled

<Tip>
  **Save Your Key**: API keys are typically only shown once when you create them. Copy and save your
  key before pasting it into Valiyou.
</Tip>

## What Data Is Sent to Your Provider

When AI features are used, the following valuation data is sent to your chosen provider:

### What Is Sent

- Valuation dates
- Financial metrics (revenue, sales values)
- Media metrics (impressions, views, CPM rates)
- Brand scores

### What Is NOT Sent

- Organization name or identifier
- Personal user identities
- Any data outside of the valuation fields listed above

<Info>
  **Your DPA applies**: Because you configure your own provider account, all data processing is
  governed by your organization's agreement with that provider. Valiyou does not intermediate the
  data relationship.
</Info>

All major providers are SOC 2 Type II certified and do not train their models on API data.

### Provider Privacy Policies

- [Anthropic Privacy](https://www.anthropic.com/privacy)
- [OpenAI API Data](https://openai.com/enterprise-privacy)

- [AWS Privacy](https://aws.amazon.com/privacy/)
- [Google Cloud Privacy](https://cloud.google.com/terms/cloud-privacy-notice)

## What AI Features Use This Connection

When Private AI Connection is configured and connected, it applies to:

1. **AI Key Insights in Reports** — analysis of your multi-valuation comparison reports
2. **AI Chat Assistant** — the in-app AI assistant conversations

Both features fall back to Valiyou's built-in AI when Private AI Connection is disabled or not configured.

## What AI Key Insights Analyzes

The AI receives comprehensive data from all selected valuations:

### Financial Metrics

- Total valuation amounts
- Sales revenue (transfers, merchandise, tickets)
- Growth rates and trends
- Revenue mix analysis

### Media Metrics

- Media impressions (print, digital, social, broadcast)
- Media value calculations
- Platform-specific performance
- Engagement rates

### Brand Metrics

- Brand exposure value
- Sponsorship coverage
- Marketing effectiveness
- Brand visibility trends

### Comparative Analysis

- Year-over-year changes
- Performance benchmarks
- Trend identification
- Anomaly detection

## Best Practices

### Compare 3-5 Valuations

Optimal number for meaningful insights:

- 2 valuations: Basic comparison
- 3-5 valuations: Trend analysis (recommended)
- 6+ valuations: May slow analysis

### Use Consistent Date Ranges

For best trend analysis:

- Select valuations from similar time periods
- Compare the same season or quarter when possible
- Avoid mixing different valuation types

### Review and Interpret

AI insights are analytical starting points, not directives:

- Use as a starting point for analysis
- Verify insights against actual data
- Apply domain knowledge and context

## Troubleshooting

### Plugin Shows "Setup Required"

**Cause**: Plugin is enabled but credentials are missing or incomplete.

**Fix**: Open the configuration modal (gear icon), enter your API key, and save.

### "Invalid API Key" Error

**Causes**:

- API key expired or revoked
- Wrong provider selected
- Extra spaces from copy/paste

**Fix**:

1. Verify the provider selection matches your API key
2. Check for extra spaces when pasting
3. Generate a new API key from your provider
4. Ensure the key starts with the correct prefix:
   - Anthropic: `sk-ant-...`
   - OpenAI: `sk-...`
   - Gemini: `AIza...`

### Plugin Shows "Unhealthy"

**Causes**:

- API key invalid or expired
- Rate limit exceeded
- Provider service unavailable
- Insufficient credits

**Fix**:

1. Check API key validity in your provider dashboard
2. Wait for rate limit reset (usually hourly)
3. Check provider status page
4. Add credits to your account
5. Try disabling and re-enabling the plugin

### AI Features Still Use Valiyou AI

**Check**:

- Plugin status shows "Connected" (green), not "Setup Required" (yellow)
- Credentials were saved successfully
- Provider badge in Reports shows your provider name, not "Valiyou AI"

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Do I need Private AI Connection to use AI Insights in Reports?">
    No. AI Key Insights in Reports are available on all Professional and Enterprise plans using
    Valiyou's built-in AI — no plugin or configuration needed. Private AI Connection is only needed
    if you want to route AI processing through your own provider account under your own DPA.
  </Accordion>

  <Accordion title="Which provider should I choose?">
    If you already have an enterprise agreement with a provider, use that one. Otherwise:

    - **Anthropic Claude 3.5 Sonnet**: Excellent reasoning and analysis quality
    - **OpenAI GPT-4o**: Strong general performance
    - **Google Gemini 1.5 Pro**: Good balance of speed and quality
    - **Azure OpenAI / Vertex AI / Bedrock**: Use these when you need managed cloud infrastructure
      with regional hosting guarantees

  </Accordion>

<Accordion title="Is my valuation data shared with the AI provider?">
  Yes, valuation data (dates, financial metrics, media metrics, brand scores) is sent to your chosen
  provider's API for analysis. Organization names and personal user identities are NOT included.
  Because you configure your own provider account, data processing is governed by your DPA with that
  provider.
</Accordion>

<Accordion title="Can I switch providers later?">
  Yes. Open the plugin configuration at any time, select a new provider, enter the new credentials,
  and save. The change takes effect immediately. Previous insights already displayed in Reports are
  not affected.
</Accordion>

<Accordion title="What happens if I disable Private AI Connection?">
  All AI features fall back to Valiyou's built-in AI. Your saved credentials are preserved — if you
  re-enable the plugin, you don't need to re-enter them.
</Accordion>

  <Accordion title="What happens if my API key expires or runs out of credits?">
    The plugin will show an "Unhealthy" status. AI features will not work until you update your
    credentials or add credits in your provider dashboard. Valiyou's built-in AI is NOT used as a
    fallback when the plugin is enabled but unhealthy — fix the credentials to restore functionality.
  </Accordion>
</AccordionGroup>
