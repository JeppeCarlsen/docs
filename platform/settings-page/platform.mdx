# Platform Settings & Base Currency

<Frame>
  <img src="/images/platform/settings/platform-tab.png" alt="Valiyou platform settings interface showing base currency configuration and financial settings options" />
</Frame>

**The Platform Settings tab allows you to configure core financial settings including base currency selection for your entire organization.** This centralized currency configuration ensures consistency across all valuations, sponsorship packages, financial reports, and player transfer values. Platform settings affect how monetary values are displayed and calculated throughout Valiyou.

## Base Currency

<Frame>
  <img src="/images/platform/settings/base-currency.png" alt="Base currency selection dropdown showing available currencies including EUR, USD, GBP, DKK, SEK, and NOK" />
</Frame>

Select your organization's default currency for all financial calculations and displays.

**Available Currencies**:
- EUR (€) - Euro
- USD ($) - US Dollar
- GBP (£) - British Pound
- DKK (kr) - Danish Krone
- SEK (kr) - Swedish Krona
- NOK (kr) - Norwegian Krone
- And more...

**How to Change Currency**:
1. Navigate to **Platform** → **Settings**
2. Open **Platform** tab (default)
3. Select your preferred currency from dropdown
4. Click **"Save Currency"** button
5. Confirmation message appears

**Where Currency Is Used**:
- New valuations (default currency)
- Sponsorship packages and proposals
- Financial reports and analytics
- Player transfer values
- Revenue calculations
- Export files (PDF, CSV)

<Info>
**Currency Symbol**: The selected currency's symbol (€, $, £, kr, etc.) automatically appears throughout the platform next to all monetary values.
</Info>

<Warning>
**Existing Data**: Changing currency does NOT convert existing values. Only affects new records. Existing valuations and packages keep their original currency.
</Warning>

## Permission Requirements

<Warning>
**Permission Required**: You need the "Settings" permission to access and edit these settings. If you don't see the Settings page, contact your admin.
</Warning>

## Common Use Cases

### Initial Currency Setup

1. Navigate to **Platform** → **Settings** → **Platform** tab
2. Select your organization's primary currency
3. Click "Save Currency"
4. Verify currency symbol appears correctly in platform

### Changing Currency Mid-Year

1. **Export all current data** (valuations, reports) for records
2. Open **Platform** → **Settings** → **Platform** tab
3. Select new currency from dropdown
4. Click "Save Currency"
5. **Note**: Existing records keep original currency
6. New valuations use new currency
7. Update team about currency change

## Troubleshooting

### Currency Not Changing

**Reasons**:
- No Settings permission
- Currency not saved (must click Save button)
- Browser error (check console)

**Fix**:
- Request Settings permission from admin
- Click "Save Currency" after selecting
- Refresh page and try again
- Check network connection

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="What happens to existing valuations when I change the base currency?">
    Changing the base currency only affects new records created after the change. Existing valuations, sponsorship packages, and financial reports retain their original currency. The system does not automatically convert existing monetary values. If you need to update existing records to the new currency, you'll need to edit them individually or recreate them.
  </Accordion>

  <Accordion title="Can I use multiple currencies in different valuations?">
    Yes, while the platform currency sets the default for new records, you can manually change the currency for individual valuations when creating or editing them. This multi-currency support allows you to work with different currencies based on client requirements or regional needs.
  </Accordion>

  <Accordion title="Which currencies are supported in Valiyou platform settings?">
    Valiyou supports all major global currencies including EUR (Euro), USD (US Dollar), GBP (British Pound), DKK (Danish Krone), SEK (Swedish Krona), NOK (Norwegian Krone), and many more. The currency selector includes both European and international currencies commonly used in sports sponsorship and valuation.
  </Accordion>

  <Accordion title="How does base currency affect sponsorship packages and proposals?">
    The base currency setting determines the default currency used when creating new sponsorship packages and proposals. All pricing, revenue calculations, and financial metrics within packages will display using the selected currency symbol. This ensures consistency across all sponsor communications and internal calculations.
  </Accordion>

  <Accordion title="Will changing currency affect my financial reports and analytics?">
    New reports generated after a currency change will use the new default currency. However, historical reports and exported files retain their original currency. For accurate financial reporting across currency changes, we recommend exporting all current reports before making the change and clearly documenting the transition date.
  </Accordion>

  <Accordion title="Can I change the platform currency after creating valuations?">
    Yes, you can change the platform currency at any time. However, this only affects new records created after the change. Existing valuations will retain their original currency and will not be automatically converted. For best practices, export all existing data before making a currency change.
  </Accordion>

  <Accordion title="What permissions do I need to modify platform currency settings?">
    You need the "Settings" permission to access and modify platform settings including currency configuration. This permission is typically granted to administrators and senior team members. If you cannot access the Settings page, contact your organization administrator to request the appropriate permissions.
  </Accordion>

  <Accordion title="How does the currency symbol appear throughout the platform?">
    Once you set the base currency, its symbol (€, $, £, kr, etc.) automatically appears next to all monetary values throughout Valiyou. This includes valuation displays, sponsorship package pricing, financial reports, player transfer values, revenue calculations, and all export files (PDF and CSV).
  </Accordion>

  <Accordion title="Is there a currency conversion feature in platform settings?">
    Platform settings do not include automatic currency conversion. When you change the base currency, existing values remain in their original currency. If you need to convert values, you'll need to manually update records using current exchange rates. The currency setting is primarily for display and new record creation.
  </Accordion>

  <Accordion title="How do I ensure consistency when changing from one currency to another?">
    To ensure consistency when changing base currency: (1) Export all existing data for records, (2) Document the exact date and time of the currency change, (3) Communicate the change to all team members, (4) Create clear internal guidelines about which currency to use for different scenarios, (5) Verify that new records are created with the correct currency after the change.
  </Accordion>
</AccordionGroup>
