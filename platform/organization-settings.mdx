Comprehensive organization configuration including master data, branding, default values, SSO, audit log, and organization management.

## Accessing Settings

Navigate to **Platform** → **Settings** from the sidebar to access organization configuration.

<Note>
**Permission Required**: Most settings require "Settings" permission. SSO and Audit Log require additional permissions (see Permissions section).
</Note>

## Page Layout

The Settings page has three tabs:

### General Tab
- Organization details (name, address, VAT number)
- Logo upload with crop tool
- Base currency selection
- Default brand value indicators (Professional/Enterprise)

### SSO Tab (Enterprise only)
- SAML 2.0 configuration
- OAuth 2.0 setup
- OpenID Connect integration

### Advanced Tab
- View Audit Log button (Enterprise only)
- Danger zone: Delete organization

## General Settings

### Upload Organization Logo

Your logo appears throughout the platform, in reports, on proposals, and in sponsor communications.

**Upload Process**:
1. Click the **avatar circle** at the top of the General tab
2. Select an image file from your computer (or drag & drop)
3. **Crop and adjust** using the crop modal:
   - Zoom slider to adjust size
   - Drag image to reposition
   - Preview shows final result
4. Click "Save" to apply changes

**Logo Upload Modal**:
- Shows current logo (if exists)
- Zoom slider (0-100%)
- Pan/drag capability
- Square crop preview
- Save and Cancel buttons
- Delete button (to remove existing logo)

<Tip>
**Drag & Drop**: You can also drag an image file directly onto the avatar circle to upload. No need to click first!
</Tip>

<Info>
**Supported Formats**: JPG, PNG, GIF, WebP
**Max File Size**: 2MB
**Output**: Automatically cropped to square format
</Info>

**To Remove Logo**:
1. Click the avatar circle with your current logo
2. Click "Delete" button in the crop modal
3. Confirm removal
4. Avatar circle returns to default state

**Where Logo Appears**:
- Settings page avatar circle
- Top navigation bar
- Valuation reports (PDF exports)
- Sponsorship proposals (PDF and external view)
- Email communications to sponsors
- Organization profile

### Organization Details

Master data for your organization used in documents, reports, and legal contexts.

**Fields**:
- **Organization Name** (required) - Your company or club name
- **Street** (optional) - Street name
- **House Number** (optional) - Building number
- **Postal Code** (optional) - ZIP/postal code
- **City** (optional) - City name
- **Country** (optional) - Select from EU countries dropdown
- **CVR/VAT Number** (optional) - Tax identification number with country selector

**CVR/VAT Number Field**:
- Country selector dropdown (DK, DE, SE, NO, UK, etc.)
- Number input field
- Format examples shown in placeholder
- Used for invoice generation and tax compliance

**Save Button**: "Save Club Settings" (saves all organization details)

<Warning>
**Permission Required**: You need the "Settings" permission to edit organization details. If you don't see edit fields, contact your admin.
</Warning>

**Where Details Are Used**:
- Legal documents and contracts
- Invoices and receipts
- Sponsorship proposals
- Reports and exports
- Email footers
- Public profiles (if enabled)

### Base Currency

<Frame>
  <img src="/images/platform/organization-settings/base-currency.png" alt="Base Currency Settings" />
</Frame>

Select your organization's default currency for all financial calculations and displays.

**Available Currencies**:
- EUR (€) - Euro
- USD ($) - US Dollar
- GBP (£) - British Pound
- DKK (kr) - Danish Krone
- SEK (kr) - Swedish Krona
- NOK (kr) - Norwegian Krone
- And more...

**How to Change Currency**:
1. Open currency dropdown in General tab
2. Select your preferred currency
3. Click **"Save Currency"** button
4. Confirmation message appears

**Where Currency Is Used**:
- New valuations (default currency)
- Sponsorship packages and proposals
- Financial reports and analytics
- Player transfer values
- Revenue calculations
- Export files (PDF, CSV)

<Info>
**Currency Symbol**: The selected currency's symbol (€, $, £, kr, etc.) automatically appears throughout the platform next to all monetary values.
</Info>

<Warning>
**Existing Data**: Changing currency does NOT convert existing values. Only affects new records. Existing valuations and packages keep their original currency.
</Warning>

## SSO Settings (Enterprise)

<Frame>
  <img src="/images/platform/organization-settings/sso-settings.png" alt="SSO Settings" />
</Frame>

<Note>
**Plan Required**: Enterprise plan only
**Permission Required**: Admin or SSO management permission
</Note>

Configure Enterprise Single Sign-On (SSO) for your organization, allowing team members to log in using your organization's identity provider.

**Supported Protocols**:
- **SAML 2.0** - Industry-standard authentication protocol
- **OAuth 2.0** - Modern authorization protocol
- **OpenID Connect** - Identity layer built on OAuth 2.0

**Supported Identity Providers**:
- Okta
- Azure Active Directory (Microsoft Entra ID)
- Google Workspace
- OneLogin
- Auth0
- Custom SAML/OAuth providers

**SSO Configuration Fields**:
- Provider type selection
- Entity ID / Issuer URL
- SSO URL / Login URL
- Certificate upload (X.509)
- Attribute mapping
- JIT (Just-In-Time) provisioning toggle

**Benefits of SSO**:
- Single set of credentials for all tools
- Centralized user management
- Enhanced security (MFA, conditional access)
- Simplified onboarding/offboarding
- Compliance with corporate policies

<Info>
**Contact Support**: SSO configuration requires technical setup. Contact support@valiyou.com for assistance with SSO setup and testing.
</Info>

**SSO Login Flow**:
1. User clicks "Sign in with SSO" on login page
2. Redirected to identity provider
3. Authenticates with corporate credentials
4. Redirected back to Valiyou with session
5. Automatically logged in (or account created via JIT)

## Advanced Settings

### Audit Log (Enterprise)

<Note>
**Plan Required**: Enterprise plan only
**Permission Required**: Admin permission
</Note>

Access comprehensive audit trail of all data changes in your organization.

**Button**: "View Audit Log" (opens full audit log page)

**What Is Tracked**:
- **Who**: User name and email who made the change
- **What**: Before and after values (complete diff)
- **When**: Precise timestamp (date and time)
- **Where**: Table name and record ID
- **How**: Action type (create, update, delete)

**Tracked Resources**:
- Valuations (create, update, delete, status changes)
- Organization settings (all fields)
- User permissions and roles
- Player transfers and sales
- Sponsorship packages and proposals
- Sponsor contacts and details
- Library items and categories
- All other critical data

**Audit Log Page Features**:
- Searchable by user, action, resource type
- Date range filtering
- Sortable columns
- Export to CSV
- Detailed change diff viewer
- Pagination for large datasets

<Info>
**Retention**: Audit logs are retained indefinitely for compliance purposes. Contact support for specific retention policy questions.
</Info>

**Use Cases**:
- **Compliance Audits**: GDPR, SOX, financial regulations
- **Security Investigations**: Track unauthorized access or suspicious activity
- **Team Activity Monitoring**: Review team member actions
- **Data Forensics**: Investigate data changes or errors
- **Training**: Identify areas where team needs guidance
- **Dispute Resolution**: Verify who made changes and when

**See Also**: [Platform → Audit Log](/platform/audit-log) for detailed audit log documentation.

### Danger Zone: Delete Organization

<Warning>
**Owner Only**: Only the organization owner can delete the organization. This action is permanent after 30 days.
</Warning>

Permanently delete your organization and all associated data.

**What Happens Immediately**:
- Stripe subscription cancelled (at end of current billing period)
- Organization hidden from all members
- Members lose access to organization
- Offboarding email sent to owner with reactivation link

**What Happens After 30 Days (Permanent Deletion)**:
- All valuations and player transfers
- All organization members and pending invitations
- All sponsorship packages, proposals, and sponsors
- All settings, SSO providers, and entitlements
- All audit logs and historical data
- Organization name becomes available for reuse

<Info>
**30-Day Grace Period**: You can reactivate your organization within 30 days using the link in the offboarding email. After 30 days, data is permanently deleted.
</Info>

**Deletion Process**:

1. **Click "Delete Organisation"** button in Danger Zone
2. **Read warnings carefully** in confirmation modal
3. **Type exact organization name** to confirm (case-sensitive)
4. **Click "Delete Organisation"** in modal
5. **Check email** for offboarding message with reactivation link
6. **Save reactivation link** (valid for 30 days only)

**Confirmation Modal**:
- Red border and warning colors
- Lists all data that will be deleted
- Requires exact organization name match
- "Delete Organisation" button (red, disabled until valid)
- "Cancel" button (gray)

**Offboarding Email Contents**:
- Confirmation of deletion request
- 30-day grace period explanation
- Reactivation link (valid for 30 days)
- Contact support information
- Data export instructions (if needed)

<Tip>
**Reactivation**: If you change your mind, simply click the reactivation link in your offboarding email within 30 days. Your organization and all data will be restored immediately.
</Tip>

**Alternatives to Deletion**:
- **Downgrade plan**: Cancel subscription but keep data
- **Export data**: Download valuations and reports first
- **Transfer ownership**: Assign new owner instead of deleting
- **Archive organization**: Keep data but stop using platform

## Permissions

Different settings require different permission levels:

| Setting | Required Permission | Plan Requirement |
|---------|-------------------|-----------------|
| **Organization Details** | Settings permission | All plans |
| **Upload Logo** | Settings permission | All plans |
| **Base Currency** | Settings permission | All plans |
| **Brand Value Indicators** | Settings permission | Professional or Enterprise |
| **SSO Configuration** | Admin or SSO permission | Enterprise only |
| **View Audit Log** | Admin permission | Enterprise only |
| **Delete Organization** | Owner only | All plans |

<Info>
**Missing Features?** If you don't see certain settings or features, check:
1. Your plan tier (Starter, Professional, or Enterprise)
2. Your user permissions (ask admin or owner)
3. Organization ownership status
</Info>

## Common Use Cases

### Initial Organization Setup

1. Navigate to **Platform** → **Settings**
2. **General tab**:
   - Upload organization logo
   - Fill in organization details (name, address, VAT number)
   - Select base currency
   - Set default brand values (Professional/Enterprise)
3. **SSO tab** (Enterprise only):
   - Configure identity provider
   - Test SSO login
4. Invite team members

### Updating Organization Branding

1. Open **Settings** → **General** tab
2. Click avatar circle
3. Upload new logo
4. Crop and adjust
5. Save changes
6. Verify logo appears in navigation bar

### Changing Currency Mid-Year

1. **Export all current data** (valuations, reports) for records
2. Open **Settings** → **General** tab
3. Select new currency from dropdown
4. Click "Save Currency"
5. **Note**: Existing records keep original currency
6. New valuations use new currency
7. Update team about currency change

### Enabling SSO for Team (Enterprise)

1. Contact support@valiyou.com to begin SSO setup
2. Provide identity provider details
3. Work with support to configure SAML/OAuth
4. Test SSO login with admin account
5. Enable JIT provisioning (optional)
6. Roll out SSO to team
7. Communicate SSO login instructions

### Investigating Data Changes (Enterprise)

1. Navigate to **Settings** → **Advanced** tab
2. Click "View Audit Log"
3. Filter by:
   - Date range (when did change occur?)
   - User (who made the change?)
   - Resource type (what was changed?)
4. Review change details
5. Export audit log if needed for compliance

### Offboarding Organization

1. **Export all data** (valuations, reports, sponsor lists)
2. **Notify team members** of pending deletion
3. Navigate to **Settings** → **Advanced** tab
4. Click "Delete Organisation" in Danger Zone
5. Read warnings carefully
6. Type exact organization name
7. Confirm deletion
8. **Save reactivation link** from email (valid 30 days)
9. Verify Stripe subscription cancelled

## Troubleshooting

### Can't Upload Logo

**Check**:
- File size under 2MB
- File format is JPG, PNG, GIF, or WebP
- Browser allows file uploads (not blocked)
- You have Settings permission

**Try**:
- Compress image file
- Convert to different format
- Clear browser cache
- Try different browser
- Drag and drop instead of clicking

### Currency Not Changing

**Reasons**:
- No Settings permission
- Currency not saved (must click Save button)
- Browser error (check console)

**Fix**:
- Request Settings permission from admin
- Click "Save Currency" after selecting
- Refresh page and try again
- Check network connection

### SSO Not Working

**Common Issues**:
- Incorrect Entity ID or SSO URL
- Certificate expired or invalid
- Attribute mapping incorrect
- JIT provisioning disabled

**Solution**:
- Contact support@valiyou.com for SSO troubleshooting
- Verify identity provider configuration
- Test with admin account first
- Check browser console for errors

### Can't Delete Organization

**Reasons**:
- Not organization owner (only owner can delete)
- Organization name typed incorrectly (case-sensitive)
- Browser JavaScript error

**Fix**:
- Transfer ownership to yourself first
- Type exact organization name (check capitalization)
- Try different browser
- Contact support if ownership transfer needed
