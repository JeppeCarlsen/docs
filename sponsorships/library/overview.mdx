Create a reusable library of sponsorship items that can be mixed and matched to build custom packages for sponsors.

## Accessing Library

Navigate to **Sponsorships** → **Library** from the sidebar to access the item library.

<Note>
**Plan Required**: Library feature requires Professional or Enterprise plan.
**Permission Required**: You need Library role or Admin access.
</Note>

## Page Layout

The Library page has three tabs:

### Library

Sortable table showing all sponsorship items with:
- Drag-and-drop reordering
- Item name and description
- Category, tier, and event assignments
- Unit cost and max quantity
- Inline editing capabilities
- Quick edit and delete actions

### Settings

Configuration for:
- **Categories** - Item type classification (Designation, Hospitality, etc.)
- **Tiers** - Sponsorship tier levels (Gold, Silver, Bronze, etc.)
- **Events** - Event definitions with location and date ranges

### Negotiator

Configuration for contribution margin ratio labels used in Package Builder negotiator mode.

## Empty State

If you don't have any items yet, you'll see:

- **Icon**: Document graphic
- **Title**: "No items yet"
- **Message**: "Add your first sponsorship item to the library."
- **Action**: "Add First Item" button
