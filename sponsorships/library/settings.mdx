Configure categories, tiers, and events used throughout the sponsorship module.

## Categories Settings

**Card Title**: "Categories"

**Features:**
- Add new category button
- List of existing categories
- Edit/delete buttons per category
- Color indicators (visual organization)

**Built-in Categories:**
- Designation (cannot be deleted)
- Hospitality (cannot be deleted)

**Custom Categories:**
- Add unlimited custom categories
- Edit name and color
- Delete when no longer needed

<Warning>
**Cannot Delete**: Categories with items assigned cannot be deleted. Reassign or delete items first.
</Warning>

## Tiers Settings

**Card Title**: "Tiers"

**Features:**
- Add new tier button
- Drag-and-drop reordering (priority levels)
- Edit/delete buttons per tier
- List shows: tier name, order

**Common Tier Examples:**
- Platinum
- Gold
- Silver
- Bronze
- Standard

<Info>
**Tier Order**: The order determines priority in Package Builder. Top = highest tier, bottom = lowest tier.
</Info>

## Events Settings

**Card Title**: "Events"

**Features:**
- Add new event button
- List of existing events
- Edit/delete buttons per event
- Shows: event name, location, period

**Event Details:**
- **Name** - Event identifier
- **Location** - Venue name and full address
- **Period** - Start and end dates
- **Description** - Additional notes

**Common Event Examples:**
- 2024/2025 Season
- Championship Game
- Opening Ceremony
- Summer Tour
- Annual Gala

<Tip>
**Season vs Single Event**: Create events for entire seasons or individual games depending on your sponsorship structure.
</Tip>

## Troubleshooting

### Can't Delete Category

**Reason**: Category has items assigned
**Fix**: Reassign or delete all items using this category first

### Can't Delete Tier

**Reason**: Tier has items with tier requirement
**Fix**: Change tier requirement to "All Tiers" or different tier for all items

### Can't Delete Event

**Reason**: Event has items assigned
**Fix**: Change event assignment to "All events" or different event for all items
