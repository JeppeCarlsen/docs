# Sponsorship Package Builder

<Frame>
  <img src="/images/valiyou.com_products_sponsorships_packages(iPad Pro).png" alt="Sponsorship package builder interface showing custom package creation, inventory item selection, quantity configuration, pricing calculator, and proposal generation for sports marketing packages" />
</Frame>

**Build professional sponsorship packages** with the Valiyou Package Builder. Create custom packages by selecting inventory items, setting quantities, calculating tiered pricing, and generating branded proposals for your sponsors.

From VIP hospitality bundles to comprehensive branding packages — streamline your sponsorship sales process with automated package building and proposal generation.

## Accessing Packages

Navigate to **Sponsorships** → **Packages** from the sidebar to access package management.

<Note>
**Plan Required**: Professional or Enterprise plan
**Permission Required**: Packages permission or Admin access
</Note>

## Package Workflow

The sponsorship package workflow consists of three main stages:

1. **Create Package** - Define sponsor, tier, pricing, events
2. **Build Inclusions** - Add inventory items, set quantities
3. **Send Proposal** - Preview PDF, send to sponsor contacts

## Packages List Page

### Empty State

If you don't have any packages yet, you'll see:

- **Icon**: Cube graphic
- **Title**: "No pending packages"
- **Message**: "Create sponsorship package to get started."
- **Action**: "Create Sponsorship Package" button

### Package Grid

**Layout**: Card grid (1-3 columns based on screen size)
- **Desktop (&gt;1024px)**: 3 columns
- **Tablet (640-1024px)**: 2 columns
- **Mobile (&lt;640px)**: 1 column

<Info>
**Draft Packages Only**: The packages list shows only draft packages. Approved packages appear in Proposals page.
</Info>

### Package Card

Each card displays:

**Sponsor Logo** (top):
- 128×128px circular image
- Falls back to cube icon if no logo
- Pulled from sponsor profile

**Package Name**:
- Bold, medium text
- Primary identifier

**Sponsor Name**:
- Below package name
- Gray text

**Sales Price**:
- Large, prominent currency value
- Example: "500,000 kr"

**Action Buttons** (bottom):

- **Inclusions** - Open Package Builder

<Tip>

</Tip>

### New Package Button

**Location**: Top right (when packages exist)
**Button**: "New Package" (rounded, primary blue)

**Action**: Opens Create Package modal

## Create Package Modal

Modal for creating or editing package metadata.

### Modal Fields

**Package Name** (required):
- Clear, descriptive name
- Example: "Gold Partner Package", "VIP Experience Bundle"
- Appears on proposals and in lists

**Sponsor** (required):
- Dropdown of all sponsors
- Filtered by status (Active and Inactive only, no Archived)
- Shows sponsor name
- **Quick Add**: Link to create new sponsor

<Warning>
**Sponsor Required**: You must have at least one sponsor before creating a package. If no sponsors exist, you'll see a prompt to create one first.
</Warning>

**Package Tier** (required):
- Dropdown of configured tiers
- Example: Platinum, Gold, Silver, Bronze
- Determines which inventory items are available
- Affects item tier restrictions

**Sales Price** (required):
- Package selling price in base currency
- Used for coverage percentage calculation
- Example: 500,000 for €500,000
- Hidden in Negotiator Mode (proposal-based pricing)

**Events** (optional):
- Multi-select dropdown
- Choose one or more events this package applies to
- Empty = package not event-specific
- **Quick Add**: "Add event" button to create new event
- **Edit Event**: Pencil icon to view/edit event details

<Info>
**Event Filtering**: Items with event assignments will only appear in Package Builder if their event is selected here or they apply to "All events".
</Info>

**Notes** (optional):
- Internal notes about the package
- Not visible to sponsors
- Helps track context and special arrangements

### Event Management

**Add Event Button**: Opens Add Event modal with:
- Event name (required)
- Location (name, address, city, postal code, country)
- Period (start date, end date)
- Description
- Save button

**Edit Event Icon** (pencil): Opens event details modal with:
- All event information
- Edit capability
- Delete button (with affected items warning)

**Event Dropdown Features**:
- Multi-select (select multiple events)
- Checkmark indicators for selected events
- Scrollable list
- "Add event" link at bottom

### Modal Actions

**When Creating:**
- **Cancel** - Close without saving
- **Create Package** - Create package (blue button)

**When Editing:**
- **Cancel** - Close without saving
- **Delete Package** - Delete package (red button)
- **Save Changes** - Update package (blue button)

<Warning>
**Delete Package**: Deleting a package also deletes all items in that package. This action cannot be undone.
</Warning>

## Package Builder (Inclusions Page)

Comprehensive interface for adding inventory items to packages.

### Accessing Builder

**From Packages List**: Click "Inclusions" button on package card
**Direct URL**: `/products/sponsorships/packages/[id]/builder`

### Page Header

**Left Side**:
- Package name as title
- Back button (returns to Packages list)

**Right Side (Action Buttons)**:
- **Edit Package** - Pencil icon, opens package metadata modal
- **Preview PDF** - Document icon, opens PDF preview
- **Send Proposal** - Envelope icon, opens send proposal modal

<Info>
**Save Status**: Changes save automatically as you work. No manual save button needed.
</Info>

### Summary Stats (Top Cards)

Four summary cards showing package metrics:

#### Total Cost

**Label**: "Total Cost"
**Value**: Sum of all included items × quantities
**Format**: Currency (e.g., "€450,000")
**Hidden**: In Negotiator Mode

#### Sales Price

**Label**: "Sales Price"
**Value**: Package sales price from metadata
**Format**: Currency
**Hidden**: In Negotiator Mode

#### Coverage Percentage

**Label**: "Coverage"
**Value**: (Total Cost ÷ Sales Price) × 100
**Format**: Percentage (e.g., "90%")
**Color**:
- Green: 75-100%+
- Yellow: 50-75%
- Orange: 25-50%
- Red: 0-25%

**Negotiator Mode**: Shows label instead of percentage (e.g., "High Coverage")

<Tip>
**Healthy Coverage**: Aim for 75-100% coverage. This means item costs closely match sales price, making the package realistic and balanced.
</Tip>

#### Contribution Margin

**Label**: "Contribution Margin"
**Value**: Sales Price - Total Cost
**Format**: Currency
**Hidden**: In Negotiator Mode

### Event Filter (if applicable)

**Displays when**: Package has events assigned

**Dropdown**: "All Events" or specific event selection
**Purpose**: Filter inventory items by event assignment
**Behavior**:
- "All Events" - Show all items
- Specific Event - Show only items for that event + "All events" items

<Info>
**Smart Filtering**: Items assigned to different events than selected are automatically hidden to prevent confusion.
</Info>

### Inclusions Table

Sortable table with all available inventory items.

#### Table Columns

**Drag Handle** (leftmost):
- Six-dot icon
- Click and drag to reorder included items
- Only works for included items (checked)
- Changes sort_order in database

**Checkbox**:
- Toggle item inclusion
- Checked = included in package
- Unchecked = not included
- Disabled for tier-restricted items

**Item Name**:
- Bold, prominent
- Shows description below (if exists)
- Gray text for description

**Required Tier**:
- Gray badge showing tier requirement
- Only shown for tier-restricted items
- Empty if "All Tiers"

**Quantity**:
- **Boolean Items**: Shows "YES" badge when included
- **Quantity Items**: Plus/minus buttons with number
  - Minus button: Decrease quantity
  - Number: Current quantity
  - Plus button: Increase quantity
- **Not Included**: Shows "-"
- **Max Quantity**: Enforced automatically (can't exceed limit)

**Unit Cost**:
- Currency formatted
- Right-aligned
- Grayed out for disabled items
- Hidden in Negotiator Mode

**Total**:
- Quantity × Unit Cost
- Currency formatted
- Right-aligned
- Bold for emphasis
- Hidden in Negotiator Mode

<Warning>
**Tier Restrictions**: Items with tier requirements higher than package tier are disabled and grayed out. Upgrade package tier to access them.
</Warning>

### Sorting and Reordering

**Library Order**: Items appear in same order as Library page by default
**Drag to Reorder**:
- Only included items can be reordered
- Drag handle on left side
- New order saves automatically
- Affects proposal PDF display order

<Tip>
**Strategic Ordering**: Reorder items to group similar offerings or prioritize high-value items in proposals.
</Tip>

### Item States

**Normal (Available)**:
- White/gray background
- All controls enabled
- Can check/uncheck, adjust quantity

**Included**:
- Light blue/indigo background
- Checkmark visible
- Can adjust quantity or uncheck

**Tier-Restricted (Disabled)**:
- Grayed out appearance
- Checkbox disabled
- Shows tier requirement badge
- Hover shows reason: "Requires [Tier Name]"

**Event-Restricted (Hidden)**:
- Not shown in table
- Filtered out by event selection
- Only appears when correct event selected

### Boolean vs Quantity Items

**Boolean Items**:
- Show "YES" badge when included (no quantity input)
- Always count as 1 unit for cost calculation
- Example: "Logo on Website" (either included or not)

**Quantity Items**:
- Show plus/minus controls when included
- Start at quantity 1 when first checked
- Can increase/decrease as needed
- Max quantity enforced from library settings

<Info>
**Auto-Quantity**: Checking an item automatically sets quantity to 1 for quantity-based items. Unchecking resets to 0.
</Info>

### Custom Cover Images

Add organization-specific branding with custom PDF cover pages.

**Setup**: Platform > Settings > PDF Contract Covers

**How to Upload:**
1. Go to Platform > Settings
2. Scroll to "PDF Contract Covers" section
3. Click "Upload Cover" button
4. Select image file (PNG or JPG)
5. Cover applies to all future PDFs

<Frame>
  <img src="/images/platform/settings/pdf-cover-upload.png" alt="Upload custom PDF cover page with drag-and-drop interface for branded sponsorship proposals, supporting JPG, PNG, and PDF formats up to 5MB" />

**Cover Requirements:**
- **Format**: PNG or JPG only
- **Size**: Maximum 5 MB
- **Dimensions**: Recommended 1200x1600px (portrait, 3:4 aspect ratio)
- **Content**: Organization logo, branding, imagery

**PDF Structure with Cover:**
1. **Custom Cover Page** (your branded image) ← NEW
2. Pre-Contract Terms of Service
3. Package Details & Sponsor Info
4. Inclusions Table
5. Financial Summary
6. Post-Contract Terms of Service
7. Signature Page

<Warning>
**Professional Design**: Use high-quality, professional images for cover pages. Low-resolution or poorly designed covers create a negative first impression.
</Warning>

### Terms of Service Integration

Include custom terms and conditions in your PDFs automatically.

**Setup**: Platform > Settings > Terms of Service

**Two Types:**
- **Pre-Contract Terms** - Displayed BEFORE package details (introductory text, eligibility)
- **Post-Contract Terms** - Displayed AFTER package details (legal terms, payment terms)

**Configuration:**
1. Go to Platform > Settings > Terms of Service
2. Enter "Pre-Contract Terms" (optional intro text)
3. Enter "Post-Contract Terms" (legal terms and conditions)
4. Click "Save Terms"
5. Terms automatically included in all PDFs

<Info>
**Legal Review**: Always have your Terms of Service reviewed by legal counsel. These terms become part of binding contracts with sponsors.
</Info>

**Example Pre-Contract Terms:**
```
Thank you for your interest in partnering with [Organization].

This proposal outlines the sponsorship benefits included in your
selected package. Please review carefully before signing.

All sponsorships are subject to management approval and must
comply with our brand guidelines.
```

**Example Post-Contract Terms:**
```
TERMS AND CONDITIONS

1. Payment Terms: Full payment due within 30 days of signing.
2. Cancellation: 90 days written notice required.
3. Rights: Sponsor may not transfer agreement without consent.

By signing, Sponsor agrees to all terms in this agreement.
```

## Negotiator Mode

Special view mode that hides unit costs and emphasizes coverage percentages.

### Enabling Negotiator Mode

**Location**: Settings menu (global toggle)
**Effect**: Applied across entire Sponsorships module

### Changes in Negotiator Mode

**Summary Cards**:
- ❌ Total Cost - Hidden
- ❌ Sales Price - Hidden
- ✅ Coverage - Shows label instead of percentage
- ❌ Contribution Margin - Hidden

**Inclusions Table**:
- ❌ Unit Cost column - Hidden
- ❌ Total column - Hidden
- ✅ Quantity column - Still visible
- ✅ All other columns - Unchanged

**Coverage Labels** (configured in Library → Negotiator tab):
- 0-25%: "Very Low Coverage"
- 25-50%: "Low Coverage"
- 50-75%: "Medium Coverage"
- 75-100%: "High Coverage"
- 100%+: "Full Coverage"

<Info>
**Use Case**: Negotiator Mode is useful for proposal-based pricing strategies where you want to focus on value delivery rather than explicit costs.
</Info>

## Common Use Cases

### Creating First Package

1. Click "Create Sponsorship Package"
2. Fill in package name, sponsor, tier, sales price
3. Select events (if applicable)
4. Add notes (optional)
5. Click "Create Package"
6. Click "Inclusions" on package card
7. Check items to include
8. Adjust quantities as needed
9. Preview PDF
10. Send proposal to sponsor contacts

### Building Multi-Tier Packages

1. Create packages for each tier (Gold, Silver, Bronze)
2. Use same sponsor or different sponsors
3. Assign correct tier to each package
4. Include tier-appropriate items (exclusive items for higher tiers)
5. Adjust pricing based on value
6. Send different proposals to different sponsors

### Event-Specific Packages

1. Create event in Library → Settings
2. Create package with event selected
3. Only event-specific items appear in Builder
4. Build package for that event only
5. Send proposal highlighting event exclusivity

### Updating Package After Creation

1. Open package from list
2. Click "Edit Package" (pencil icon)
3. Update metadata (name, sponsor, tier, price, events)
4. Save changes
5. Return to Inclusions
6. Adjust items/quantities as needed
7. Preview updated PDF
8. Resend if already sent to sponsor

## Troubleshooting

### Can't Check Item (Grayed Out)

**Reason**: Tier restriction - item requires higher tier
**Fix**: Edit package and upgrade tier, or assign item to "All Tiers" in Library

### Item Not Appearing in Builder

**Check**:
- Item event assignment matches package events
- Item tier requirement ≤ package tier
- Item is active (not deleted)
- Library → Settings has item configured

### Can't Increase Quantity

**Reason**: Hit max quantity limit
**Fix**: Go to Library, edit item, increase Max Quantity field

### PDF Preview Shows Wrong Data

**Try**:
- Refresh browser
- Clear cache
- Save Builder changes
- Re-open preview

### Send Proposal Button Disabled

**Reasons**:
- No sponsor contacts (add contacts first)
- No items included (check at least one item)
- Package already approved
- Demo mode restrictions

### Coverage Percentage Wrong

**Check**:
- Total Cost = sum of all included items × quantities
- Sales Price set correctly in package metadata
- Formula: (Total Cost ÷ Sales Price) × 100%
- Verify all item unit costs in Library

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="How do I create a sponsorship package?">
    Click "New Package" button, fill in package name, select the sponsor, choose tier level, and configure pricing mode (Cost-Plus or Negotiator). Then click "Inclusions" to add inventory items using the Package Builder. Finally, preview and send the proposal to your sponsor contacts.
  </Accordion>

  <Accordion title="What's the difference between Cost-Plus and Negotiator pricing modes?">
    Cost-Plus mode calculates sales price automatically based on unit costs plus a margin percentage (e.g., items cost €100k + 50% margin = €150k sales price). Negotiator mode hides unit costs and lets you set a custom sales price without showing cost breakdown. Use Cost-Plus for transparent pricing and Negotiator for flexible deal-making.
  </Accordion>

  <Accordion title="Can I preview the proposal before sending to sponsors?">
    Yes! The Package Builder includes a "Preview PDF" button that generates a full proposal preview with your organization branding, selected design template, inventory items, and pricing. You can customize PDF templates, upload custom cover pages, and see exactly what sponsors will receive before sending.
  </Accordion>

  <Accordion title="How does the Package Builder prevent overselling?">
    The Package Builder integrates with the inventory system and enforces max quantity limits. If an item has 50 VIP tickets available, you cannot add more than 50 to the package. The quantity input shows warnings and red borders when limits are reached, preventing accidental double-booking.
  </Accordion>

  <Accordion title="Can I create tiered packages for different sponsor levels?">
    Yes! When creating a package, select a tier (Gold, Platinum, Silver, etc.) to restrict which inventory items appear in the Package Builder. Items marked as tier-exclusive will only be available for packages at that tier level or higher. This lets you create premium packages with exclusive benefits for high-value sponsors.
  </Accordion>

  <Accordion title="What PDF design templates are available?">
    Valiyou includes three professional PDF templates: Classic (traditional blue design), Modern (contemporary purple gradient), and Minimal (clean minimalist). Each template is fully customizable with your organization logo, brand colors, and optional custom cover page. Templates are managed in Platform → Settings → Documents.
  </Accordion>

  <Accordion title="Can I include event-specific items in packages?">
    Yes! When building packages, you can include items assigned to specific events (e.g., "Championship Game VIP Box"). The Package Builder shows which event each item belongs to, allowing you to create special event packages alongside year-round offerings.
  </Accordion>

  <Accordion title="How do I send a package proposal to sponsors?">
    After building your package, click the "Send Proposal" button. This generates a branded PDF proposal and opens an email composer with sponsor contacts pre-filled. You can customize the email message and send directly to sponsors. All sent proposals are tracked in the Proposals page.
  </Accordion>

  <Accordion title="What happens to inventory when I create a package?">
    When you add items to a draft package, they're automatically RESERVED in the inventory system, reducing available quantities. If the package is approved, items become COMMITTED (locked). If rejected or deleted, items are RETURNED to available inventory. This prevents overselling across multiple packages.
  </Accordion>

  <Accordion title="Can I duplicate packages to save time?">
    Yes! Use the duplicate feature to copy existing packages with all items and quantities. This is perfect for creating "template" packages with standard configurations that you can customize for different sponsors. Simply duplicate, change sponsor name, adjust items if needed, and send.
  </Accordion>
</AccordionGroup>
