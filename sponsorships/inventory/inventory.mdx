## Inventory Management System

**Automatic quantity tracking** with full transaction history for all sponsorship items.

### How It Works

The inventory system automatically tracks available quantities using a **transaction-based approach**:

**Available = Max Quantity - Reserved - Committed**

**Transaction Types:**
- **RESERVED** - Items in draft/pending packages (not yet approved)
- **COMMITTED** - Items in approved packages (locked)
- **RETURNED** - Items returned to inventory (package rejected/archived)
- **INBOUND** - Manual stock additions (receiving new inventory)
- **ADJUSTMENT** - Manual corrections (fixing errors)

<Info>
**Real-Time Updates**: The Available column updates automatically whenever packages change status, items are added/removed, or manual adjustments are made.
</Info>

### View Transaction History

Click the **clock icon** in the Actions column to view complete transaction history for an item.

<Frame>
  <img src="/images/sponsorships/inventory/history-modal.png" alt="Sponsorship inventory transaction history modal showing chronological audit trail with reserved, committed, returned, and inbound transactions for VIP tickets and hospitality packages" />
</Frame>

**History Modal Shows:**
- **Date & Time** - When the transaction occurred
- **Type** - Transaction type (RESERVED, COMMITTED, RETURNED, etc.)
- **Quantity** - Amount changed (+ or -)
- **Package** - Which package caused the change (if applicable)
- **Notes** - Description of what happened

**Example Transactions:**
```
Dec 4, 2025 10:30 AM | RESERVED     | -5 | Gold Package      | Package item added: VIP Tickets
Dec 3, 2025 02:15 PM | COMMITTED    | -5 | Gold Package      | Package status changed to approved
Dec 2, 2025 11:00 AM | INBOUND      | +50| -                 | Received new stock shipment
Dec 1, 2025 09:45 AM | ADJUSTMENT   | +2 | -                 | Correction: Found 2 extra tickets
```

<Tip>
**Audit Trail**: Every inventory change is logged with timestamp, user, and reason. Perfect for audits and troubleshooting!
</Tip>

### Manual Inventory Adjustments

Click the **+/- icon** in the Actions column to manually adjust inventory.

<Frame>
  <img src="/images/sponsorships/inventory/adjust-modal.png" alt="Adjust inventory modal for adding stock with INBOUND and ADJUSTMENT transaction types, quantity input, and notes field for sponsorship asset management" />
</Frame>

**Adjust Inventory Modal:**
- **Current Available** - Shows current available quantity
- **Type** - Select INBOUND (adding stock) or ADJUSTMENT (correcting errors)
- **Quantity** - Amount to add (positive number)
- **Notes** - Required description of why you're adjusting

**Use Cases:**
- **INBOUND** - Receiving new stock, adding items to inventory
  - Example: "Received 50 VIP tickets from supplier"
- **ADJUSTMENT** - Fixing errors, correcting counts
  - Example: "Found 2 extra tickets in storage, updating count"

<Warning>
**Manual Adjustments Only Add**: The adjust function only adds to inventory (positive numbers). To remove items, create a draft package and mark it as rejected/archived.
</Warning>

### Automatic Package Tracking

The system automatically creates transactions when packages change:

**When Creating Package:**
- Adds RESERVED transactions for all items
- Reduces available quantity immediately
- Shows package name in transaction notes

**When Approving Package:**
- Converts RESERVED to COMMITTED
- Items remain unavailable (locked to approved package)
- Cannot be returned unless package is rejected

**When Rejecting/Archiving Package:**
- Creates RETURNED transactions
- Returns items to available inventory
- Shows original package name in notes

<Info>
**Draft vs Approved**: Draft packages reserve items (can be returned), approved packages commit items (locked until rejected).
</Info>

### Oversell Prevention

The Package Builder enforces max quantity limits:

**When Adding Items:**
- Cannot exceed available quantity
- Number input shows warning if at maximum
- Red border indicates you've reached the limit

**Inline Quantity Input:**
- Type exact number between +/- buttons
- Auto-validates against available quantity
- Pressing Enter saves immediately
- Auto-selects text when clicking field (easy replacement)

### Modal Fields

**Item Name** (required):
- Clear, descriptive name
- Appears in packages and proposals
- Example: "Stadium Naming Rights", "VIP Season Tickets"

**Description** (optional):
- Detailed explanation of the item
- Visible to sponsors in proposals
- Supports multi-line text

**Category** (required):
- Select from dropdown
- **Built-in Categories**: Designation, Hospitality
- **Custom Categories**: Add your own in Settings tab
- **Quick Add**: Click "+ Add category" to create new one instantly

<Info>
**System Categories**: "Designation" and "Hospitality" are built-in and cannot be deleted. Custom categories can be managed in Settings.
</Info>

**Event Assignment**:
- **"All events"** (default) - Item applies to all events
- **Specific Event** - Item only for one event
- **Quick Add**: Click "+ Add event" to create new event
- **Event Details**: Click pencil icon to view/edit event info

<Tip>
**Event-Specific Items**: Use this for special offerings like "Championship Game VIP Tickets" or "Opening Ceremony Banner Placement".
</Tip>

**Required Tier**:
- **"All Tiers"** (default) - Available to all sponsors regardless of tier
- **Specific Tier** - Only available to sponsors at this tier level
- **Quick Add**: Click "+ Add tier" to create new tier level
- **Tier Management**: Click pencil icon to edit tiers

<Info>
**Tier Restrictions**: Use this to create exclusive items for premium sponsors (e.g., "Platinum Lounge Access" only for Gold tier).
</Info>

**Unit Cost** (required):
- Cost per unit in base currency
- Example: €5,000 for one VIP ticket
- Used in package pricing calculations
- Hidden in Negotiator Mode (proposal-based pricing)

**Max Quantity** (optional):
- Maximum available quantity
- Empty = unlimited
- Example: 100 VIP seats, 1 stadium naming right
- Enforced in Package Builder

**Boolean Toggle**:
- **OFF** (default) - Quantity-based item
- **ON** - Yes/No checkbox item
- Boolean items ignore Max Quantity field
- Example: "Logo on Website" (either included or not)

<Warning>
**Boolean Items**: When enabled, this item becomes a simple checkbox in Package Builder (no quantity field). Use for all-or-nothing offerings.
</Warning>

## Delete Item

### Delete Confirmation Modal

**Triggered by**:
- Clicking trash icon in table
- Clicking "Delete Item" button in edit modal

**Modal Content:**
- Title: "Delete Item"
- Message: "Are you sure you want to delete '[Item Name]'?"
- **Affected Packages List**: Shows which packages use this item
- Confirm: "Delete" (red button)
- Cancel: "Cancel" (gray button)

<Warning>
**Cascading Impact**: Deleting an item removes it from all packages that use it. The packages remain, but the item is removed from their item lists.
</Warning>

### Affected Packages

If the item is used in packages, the modal displays:

**Section**: "Packages using this item"

**Example**:
- Gold Partner Package
- Platinum Sponsor Bundle
- VIP Experience Package

<Info>
If the item isn't used in any packages, this section is hidden and deletion is safe.
</Info>

## Reordering Items

### Drag-and-Drop Functionality

**How to Reorder:**
1. Hover over item row
2. Click and hold the six-dot drag handle (leftmost column)
3. Drag item up or down
4. Release to drop in new position
5. Order saves automatically

**Why Order Matters:**
- Items appear in Package Builder in this order
- Organize by importance, category, or alphabetically
- Strategic ordering improves package building UX

<Tip>
**Best Practice**: Group similar items together (e.g., all VIP hospitality items, then all signage items, then all digital items).
</Tip>

## Boolean vs Quantity Items

Two types of items serve different purposes:

### Quantity-Based Items (Default)

**Characteristics:**
- Has Max Quantity field
- Shown with quantity selector in Package Builder
- Example: "VIP Tickets" (max 100)

**Use Cases:**
- Physical items with limited availability
- Tickets, seats, parking spaces
- Merchandise quantities
- Advertising impressions with caps

### Boolean Items (Checkbox)

**Characteristics:**
- Boolean toggle ON
- No quantity field (always 1 or 0)
- Shown as checkbox in Package Builder
- Example: "Logo on Website" (yes/no)

**Use Cases:**
- All-or-nothing offerings
- Digital placements (logo on website, social media mention)
- Rights and naming (stadium naming, jersey sponsor)
- Exclusive benefits (backstage access, meet-and-greet)

<Info>
**When to Use Boolean**: If the item can't have a quantity (it's either included or not), use boolean mode. If sponsors can have multiple (1, 2, 5 units), use quantity mode.
</Info>

## Tier Requirements

Restrict item availability by sponsorship tier level.

### All Tiers (Default)

**Setting**: Required Tier = "All Tiers"
**Availability**: All sponsors regardless of tier
**Use Cases**: Standard items available to everyone

### Tier-Restricted Items

**Setting**: Required Tier = Specific tier (e.g., "Gold")
**Availability**: Only sponsors at this tier or higher
**Use Cases**: Exclusive premium offerings

**Example Tier Structure:**
- **Platinum Tier**: All items (including Platinum-exclusive)
- **Gold Tier**: Gold + Silver + Bronze items (no Platinum-exclusive)
- **Silver Tier**: Silver + Bronze items (no Gold/Platinum-exclusive)
- **Bronze Tier**: Bronze items only (no premium items)

<Info>
**Tier Hierarchy**: When using tier restrictions, ensure your tier order in Settings reflects the hierarchy (Platinum > Gold > Silver > Bronze).
</Info>

## Event Assignments

Control which events items apply to.

### All Events (Default)

**Setting**: Event = "All events"
**Availability**: Item available for all events
**Use Cases**: Year-round offerings, season-long benefits

### Event-Specific Items

**Setting**: Event = Specific event (e.g., "Championship Game")
**Availability**: Item only for this event
**Use Cases**: Special event exclusives, limited-time offers

**Example Event Items:**
- "Championship Game VIP Box" - only for championship event
- "Season Opener Banner" - only for opening game
- "Annual Gala Table" - only for yearly gala event

<Tip>
**Seasonal Strategy**: Create "2024/2025 Season" event for season-long items, plus individual events for special games/occasions.
</Tip>

## Common Use Cases

### Building Initial Library

1. Go to Settings tab
2. Create categories (Digital, Hospitality, Events, etc.)
3. Create tier levels (Platinum, Gold, Silver, Bronze)
4. Create events (2024/2025 Season, Championship Game, etc.)
5. Go to Library tab
6. Add items with appropriate categories, tiers, events
7. Set unit costs and max quantities
8. Reorder items for logical Package Builder flow

### Creating Tier-Exclusive Offers

1. Create premium tier in Settings (e.g., "Platinum")
2. Add exclusive items (e.g., "CEO Meet-and-Greet")
3. Set Required Tier = "Platinum"
4. Set high unit costs
5. Use in premium packages

### Managing Event-Specific Items

1. Create event in Settings (e.g., "Annual Gala 2025")
2. Add event-specific items (e.g., "Gala VIP Table")
3. Set Event = "Annual Gala 2025"
4. Set Max Quantity = limited availability
5. Package and sell for that event only

### Updating Library Mid-Season

1. Edit existing items inline (change quantities, tiers, events)
2. Add new items as opportunities arise
3. Archive outdated items (delete if no packages use them)
4. Reorder items for better Package Builder UX
5. Update unit costs if pricing changes

## Troubleshooting

### Inline Edit Not Saving

**Try:**
- Check network connection
- Refresh page and try again
- Use Edit button modal as alternative
- Check browser console for errors

### Drag-and-Drop Not Working

**Try:**
- Use mouse (not touch) on desktop
- Check if table is scrollable (scroll into view first)
- Refresh page
- Use keyboard sensors (Tab + Space + Arrow keys)

### Item Not Appearing in Package Builder

**Check:**
- Item has correct tier requirement for sponsor
- Item has correct event assignment
- Item isn't archived/deleted
- Package Builder is filtered correctly

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="How does automatic inventory tracking work?">
    The Valiyou inventory system uses a transaction-based approach that automatically tracks available quantities. The formula is: Available = Max Quantity - Reserved - Committed. When you add items to draft packages, they're RESERVED. When packages are approved, items become COMMITTED. If packages are rejected or archived, items are RETURNED to inventory. Every transaction is logged with timestamp and details.
  </Accordion>

  <Accordion title="Can I prevent overselling sponsorship items?">
    Yes! The Package Builder enforces max quantity limits automatically. You cannot add more items to a package than are available in inventory. The system shows warnings when you reach maximum quantity and uses red borders to indicate limits. This prevents double-booking VIP tickets, hospitality packages, or limited sponsorship assets.
  </Accordion>

  <Accordion title="What's the difference between RESERVED and COMMITTED inventory?">
    RESERVED items are in draft or pending packages that haven't been approved yet. These items reduce available inventory but can be returned if the package is rejected. COMMITTED items are in approved packages and are locked until the package status changes. This two-stage system allows you to reserve items during negotiation while maintaining flexibility.
  </Accordion>

  <Accordion title="How do I view transaction history for inventory items?">
    Click the clock icon in the Actions column of any inventory item to view its complete transaction history. The history modal shows chronological records of all quantity changes including date, time, transaction type (RESERVED, COMMITTED, RETURNED, INBOUND, ADJUSTMENT), quantity changed, related package, and notes. This provides a complete audit trail for compliance and troubleshooting.
  </Accordion>

  <Accordion title="Can I manually adjust inventory quantities?">
    Yes! Click the +/- icon in the Actions column to manually adjust inventory. You can add stock using INBOUND transactions (for receiving new inventory) or ADJUSTMENT transactions (for correcting errors). Both require notes explaining the change. All manual adjustments are logged in the transaction history with your user ID and timestamp.
  </Accordion>

  <Accordion title="What are Boolean items and when should I use them?">
    Boolean items are yes/no checkbox items (either included or not) rather than quantity-based items. Use boolean mode for all-or-nothing offerings like "Logo on Website", "Stadium Naming Rights", or "Social Media Mention". Use quantity mode for items sponsors can have multiple of, like VIP tickets or parking passes.
  </Accordion>

  <Accordion title="How do tier requirements work?">
    Tier requirements restrict which sponsors can access specific inventory items. Setting an item to "Gold Tier" means only Gold sponsors (and higher tiers if you have them) can add it to packages. Set items to "All Tiers" to make them available to everyone. This is perfect for creating exclusive premium offerings for high-value sponsors.
  </Accordion>

  <Accordion title="Can I organize inventory items by drag-and-drop?">
    Yes! The six-dot drag handle in the leftmost column lets you reorder items. Simply click and drag items up or down. The new order saves automatically and determines how items appear in the Package Builder. We recommend grouping similar items together (e.g., all VIP hospitality, then signage, then digital) for easier package building.
  </Accordion>
</AccordionGroup>
